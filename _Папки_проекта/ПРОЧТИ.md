# Папки проекта: две игры (30.10.2026)

С 30.10.2026 игра разделена на две версии. **Работаем только во второй, V2.**

| Папка | Что это |
| --- | --- |
| `V2_новая_игра\` | **Новая игра V2**: база → локация → запихиваем людей в бусик → они выходят солдатами → бьют волны врагов → деньги → прокачка бусика. Канон: `docs/PRODUCT.md`. Код и сцены V2 — обычный проект (`Assets/`, ветка main). |
| `V1_старая_игра\` | **Старая игра v1** (открытый мир, город, органы). Закрыта, только чтобы доставать оттуда готовое. См. `V1_старая_игра\ПРОЧТИ.md`. |

## Что лежит в V2_новая_игра

Пока пустые папки под материалы новой игры (референсы, модели, наброски, звуки). Код и сцены Unity — как раньше в `Assets/`.

- `01_Референсы\` — картинки-ориентиры от ChatGPT: Бусик, Персонажи, Локации, База, Интерфейс.
- `02_Персонажи\` — Мирные_люди, Наши_солдаты, Враги, Спецперсонажи_пародии.
- `03_Бусик\` — Модель, Прокачка, Турель_и_оружие.
- `04_Локации\`, `05_База\`, `06_Звуки\`, `07_Интерфейс\`.
- `ПРОМПТ_ChatGPT\` — новые промпты для ChatGPT (`NN_название`, `_zip`, `_результаты`, `_архивы`).

## Что в Git

В Git попадают только эти `ПРОЧТИ.md` и пустые папки (`.gitkeep`). Тяжёлые картинки, звуки и архивы из `_Папки_проекта` остаются на компьютере Вадима (правило в `.gitignore`): лимит Git LFS на GitHub почти исчерпан (около 10,7 ГБ уже занято). Файл, который нужен игре, кладём в `Assets/` или `ArtSource/`, как раньше.
