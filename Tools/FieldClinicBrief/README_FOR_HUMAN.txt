FIELD CLINIC: один архив для локального Claude Code

1. Скачайте FIELD_CLINIC_FOR_CLAUDE.zip.
2. Поместите ZIP в корень своего Unity-проекта рядом с Assets/Packages/ProjectSettings. Если проекта пока нет, поместите ZIP в пустую рабочую папку и откройте эту папку в локальном Claude Code.
3. Откройте ЭТУ же папку в Claude Code (расширение VS Code или приложение с локальным доступом к проекту). Unity и Blender желательно открыть заранее, но агент может попросить это сделать, если не сможет сам.
4. Вставьте текст из отдельного файла CLAUDE_START_PROMPT.txt в Claude Code. Никакой ручной распаковки ZIP не требуется — агенту поручено это сделать.
5. Если агент просит авторизацию Unity Hub, системное разрешение или перезапуск, это действие нужно выполнить самому. Один архив не даёт облачному чату контроль над локальным Unity.

Внутри архива ТОЛЬКО документация, ссылки, каталог решений и девять project skills. Никаких установленных библиотек, моделей ИИ, бинарников, ассетов игры или готовых сцен.

Один и тот же архив может быть использован в локальном Codex позже, но проверки доступа каждого клиента отдельны.
