# source-command-find-texture

Use this skill when the user asks to run the migrated source command `find-texture`.

## Command Template

Use `texture-discovery` to search Poly Haven and ambientCG. State the intended
surface, target renderer or engine, resolution budget, required PBR maps, and
license/source URL for the shortlisted results. Do not transfer an asset until
its exact files and transfer size are known.
