# source-command-blender

Use this skill when the user asks to run the migrated source command `blender`.

## Command Template

Use the Blender & Texture Foundry skills for this request. Start with
`blender-modeler` for geometry, `materials` for shading, `texture-workflow` for
baking and atlas work, `texture-discovery` for CC0 texture research, and
`export-pipeline` or `unity-export` for delivery. Inspect the scene and target
constraints before changing it.
