# source-command-image-to-3d

Use this skill when the user asks to run the migrated source command `image-to-3d`.

## Command Template

Use `hunyuan3d` for image-to-textured-3D, `blender-superskill` for
reference-first Blender construction and review, and `alpha-scene-gen` when a
connected 3D provider and Blender bridge are available. Check prerequisites
before a generation. For a credit-backed provider, show the asset plan and
cost, then wait for explicit confirmation before submitting a job.
