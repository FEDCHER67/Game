## Что лежит здесь

Пока пустые папки под материалы новой игры. Код и сцены Unity — как раньше в `Assets/`.

- `00_Общее\` — общие файлы команды (у Вадима: промпт рабочего чата Феди).
- `01_Референсы\` — картинки-ориентиры от ChatGPT: Бусик, Персонажи, Локации, База, Интерфейс.
- `02_Персонажи\` — Мирные_люди, Наши_солдаты, Враги, Спецперсонажи_пародии.
- `03_Бусик\` — Модель, Прокачка, Турель_и_оружие.
- `04_Локации\`, `05_База\`, `06_Звуки\`, `07_Интерфейс\`.
- `ПРОМПТ_ChatGPT\` — новые промпты для ChatGPT (`NN_название`, `_zip`, `_результаты`, `_архивы`).

## Что в Git

В Git попадают только `ПРОЧТИ.md` и пустые папки (`.gitkeep`), правило в `.gitignore`. Картинки, звуки и архивы отсюда остаются на компьютере: лимит Git LFS на GitHub почти исчерпан (около 10,7 ГБ уже занято). Файл, который нужен игре, кладём в `Assets/` или `ArtSource/`, как раньше.
