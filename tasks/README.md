# TASKS

This folder is for significant unfinished tasks that may need to continue across sessions.

Use one file per significant active task.

Create or update a task file only when the task is:
- multi-step;
- unfinished;
- important to resume correctly later;
- too detailed for docs/CURRENT_STATE.md.

A task file should stay short and contain only:
- goal;
- current state;
- next step;
- important constraints.

Do not create task files for small one-session work.

If the same task continues, update the existing file instead of creating another one.

If a task requires USER MANUAL CHECK or explicit user acceptance, keep the task file until that decision is made.

Delete the task file only when the task is actually complete and, when applicable, explicitly accepted by the user.

docs/CURRENT_STATE.md remains the global 2–3 line current status.
