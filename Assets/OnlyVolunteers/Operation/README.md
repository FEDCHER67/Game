# Operation — прототип операции на столе (черновик, облачная сессия)

Офлайн-прототип извлечения почки по черновику `docs/drafts/OPERATION_PRESENTATION_DRAFT.md`. Только код и примитивы; сеть, остальные органы и кооп-роли пока описаны лишь в черновике.

## Запуск

1. Меню **OnlyVolunteers → Operation → Build Operation Test Scene**. Билдер создаёт `Scenes/OperationTest.unity` и материалы в `Generated/` (оба каталога в `.gitignore`: это вывод билдера).
2. Play. Клик — захватить мышь.
3. Подойти к пациенту на полу, **E** — взять. У стола **E** — положить. **Удерживать E** — пристегнуть ремни (за 6 с без ремней пациент скатится со стола). **E** — оперировать.
4. Меню органов → «Почка». Три шага: разрез скальпелем по пунктиру (ЛКМ, **Пробел** — прижать пациента), достать почку (схватить и тянуть мышь вверх, не дёргая), три полоски скотча по разрезу.
5. Почка вылетает в хотбар `LocalInventory` с ценой по качеству. **Esc** в меню — закончить операцию. Вторая почка режется с другой стороны.

| `Scripts/OperationPatient.cs` | Пациент-заглушка: перенос, ёрзание (меньше с ремнями и при «прижать»), рот-крик, запас почек. |

| `Scripts/KidneyMiniGame.cs` | Мини-игра почки: разрез → вытянуть → скотч, штрафы качества. |
| `Scripts/OrganQuality.cs` | Ступени качества и множители цены из черновика экономики. |
| `Scripts/OrganPop.cs`, `OrganDroplet.cs` | Вылет органа к хотбару, мультяшные капли. |
| `Scripts/OperationSfx.cs` | Звуки-заглушки, синтезированные в коде (имена = строки таблицы звуков в черновике). |

Скрипты лежат в Assembly-CSharp (без asmdef), как `Map/`; ссылаются на `OnlyVolunteers.Inventory` и Input System.

## Качество

Пациент приходит с качеством доставки (в сцене — Good). Операция может только понизить его: −1 ступень за кривой разрез (меньше половины длины в пределах 4,5 см от линии), −1 за рывок (почка вытянута быстрее 0,08 с). Соскальзывание скальпеля не штрафует, только останавливает разрез. Цена = базовая цена `Item_Kidney` (250) × множитель ступени (0,3 / 1 / 1,6 / 2,6 / 4,2).
