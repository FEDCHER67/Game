# Inventory — инвентарь игрока (черновик, облачная сессия)

Хотбар из 6–8 слотов для переносимых предметов (органы, инструменты) плюс наличные. Сервер — источник истины, клиент только шлёт запросы.

## Состав

| Папка | Что внутри |
| --- | --- |
| `Core/` | Чистый C# без Unity (`OnlyVolunteers.Inventory.Core`): `InventoryModel` (слоты, вместимость по размеру, стаки, выбор слота, наличные, `MostValuableItem()`, `ApplyArrestPenalty()`), `ItemStack`, `IItemCatalog`. |
| `Runtime/` | Unity + FishNet (`OnlyVolunteers.Inventory`): `ItemDefinition` / `ItemDatabase` (ScriptableObject), `WorldItem` (предмет в мире), `NetworkInventory` (серверная логика и синхронизация), `InventoryInput` (Input System), `InventoryHud` (UGUI). |
| `Tests/EditMode/` | EditMode-тесты ядра (Unity Test Framework). |
| `Items/` | Примеры: сердце, почка, печень, лёгкие, мозг, глаз, скальпель и `ItemDatabase`. Цены и размеры — заглушки (цены из неутверждённого `docs/drafts/ECONOMY_PROGRESSION_DRAFT.md`, качество Normal). |

## Правила

- Размер: сумма `Size × Count` всех предметов ≤ `capacity` (по умолчанию 12). Предмет больше вместимости в карман не помещается — его носят руками.
- Цена хранится у каждого стака (`UnitValue`): органы разного состояния не складываются в один стак.
- Полиция (канон §80): `ServerApplyArrestPenalty()` — минус 10% наличных (с округлением вниз) и изъятие одного самого дорогого предмета (наибольшая цена за штуку; при равенстве — левый слот).
- Управление: E — поднять, G — выбросить один предмет, 1–8 — выбрать слот, колесо мыши — листать. Работает только при захваченном курсоре.
- HUD: тонкая полоса внизу экрана, фон с альфой 0.18, рамки в 1 px, иконка (или короткая подпись) и счётчик; выбранный слот чуть ярче; через 3 с без изменений полоса плавно исчезает. Центр экрана не перекрывается.
