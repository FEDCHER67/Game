## Как забрать что-то из v1

Пока код v1 из main не удалён, большая часть и так на месте. После чистки:

```
git checkout v1-final -- Assets/OnlyVolunteers/Characters/SausageBuddy/Animations/Idle_Stand_v04.fbx
git checkout v1-final -- Assets/OnlyVolunteers/Characters/SausageBuddy/Animations/Idle_Stand_v04.fbx.meta
```

- Всегда берите файл **вместе с его `.meta`**: иначе Unity выдаст новый GUID, и ссылки на него сломаются.
- Папку можно взять целиком: `git checkout v1-final -- <папка>`.
- Посмотреть файл, не забирая его: `git show v1-final:<путь>`.
- Что взяли из v1, записывайте строкой в `WORK_SYNC.md` (`ported from v1: <путь>`).
