## 2. Явные допущения

- Все игроки присутствуют в сессии при продаже. Деньги не умножаются на состав. Все восемь органов могут быть извлечены и проданы, включая Damaged; смерть не удаляет товар и сама по себе не отнимает XP. Кражи, аресты, потерянные предметы и пропущенные встречи не имеют заданной частоты и не включены скрытым общим процентом потерь.

- Хутор: почка → почка → печень. Позже: глаз → глаз → почка → почка → печень → мозг → сердце → парные лёгкие. Пила/молоток уже куплены; новые виды считаются доступными только на позднем этапе. Сначала безопасные глаза, затем брюшная зона, затем самые дорогие терминальные органы. Это выбранная стратегия, не требование спеки.

- Длительность каждого фактического органа: 30/24/20/20 секунд для 1/2/3/4 игроков. По одному открытию брюшной зоны +20 секунд, черепа +35, груди +35. Четвёртый не ускоряет работу за столом относительно третьего. Расчёт не моделирует реальную параллельность зон; нет замеров удобства или скорости.

- Первая потеря ступени в теле через 85 секунд после смерти, далее каждые 40: это предложенная граница T-04, а не отдельное Confirmed. Для чувствительности ниже также проверена первая потеря через 45 секунд. Извлечённый орган сразу убирают; в основных таблицах нет дальнейшей порчи на доставке, доставка в переносном холодильнике занимает менее 25 минут. Предшествующая дробная порча равна нулю.

- Распределение врождённого качества Хутора взято из village старого скрипта: 15/60/20/5/0%; позднее из old: 5/35/40/17/3%. На каждый орган независимо накладывается один штраф ступени с вероятностью 40/25/20/20% по составу из старого черновика. Это сценарий умеренно неаккуратной игры, не статистика релиза. Качества независимы при фиксированной ветви смерти; общая смерть связывает органы NPC.

- До операций собраны два пакета крови. Шансы брюшных извлечений 30/40/50%; для глаз оставлен Confirmed 0%. Неутверждённое T-03 (+10 п.п. за кровь также к глазам) показано отдельно. При извлечении мозг/сердце/лёгкие смертельны; повторных роллов на трупе нет. Передозировка/шок не включены без частот ошибок и спасений.

- Основной денежный столбец: свежие суточные счётчики, органы одного NPC продаются от лучших к худшим, респект 2. Торг безопасный: один запрос с максимальной ожидаемой прибавкой, при отказе согласие на исходную цену. Точная встречная цена пока открыта в спеке; здесь она принята равной базе. Кровь торгуется отдельно по той же политике.

- «После прямых расходов»: минус $5 за пустой пакет крови, $5 за один мусорный пакет на NPC, номинальный наркоз $20 за применение. В каждой ветви смерти число применений = ceil(время до смерти либо конца операции / 90 секунд); наркоз после смерти не расходуется. Повторное введение без дополнительной задержки/ошибки; из ветвей получается среднее дробное потребление. Один мусорный пакет на NPC — допущение, не утверждённая вместимость для тела. Никаких обычных органных пакетов. Электричество, амортизация, поездки и персонал в этом столбце ещё не вычтены.

- NPC в таблицах доступности — целые пороги накопления при успешной продаже всех выходов; не медиана случайной игры. Покупки других веток исключены только в первой таблице; отдельная очередь покупок ниже учитывает совместные траты. Качество и насыщение XP не меняют.

## 5. Через сколько NPC доступны навыки

Хутор с новой игры: X(N)=P×(250+70N), N≥1; отдельно X(0)=55P за учебный шприц. Поздний этап: начинаем с нуля свободного XP, бонусы крови/почек/печени уже использованы, прочие виды ещё новые: X(N)=P×(700+170N), N≥1. Это два отдельных режима, а не прогноз момента переезда. Если поздние виды уже открыты, убрать 700P и считать ceil(цена/(170P)).

## 10. Проблемы и предлагаемые числа — только для обсуждения

1. **XP резко зависит от состава, денежный прогресс — гораздо слабее.** Новые поздние виды дают квартету 2 800 XP разом; первый полный поздний NPC даёт 3 480 XP при нулевом входном свободном XP. Соло на всю текущую линейку в раннем режиме нужно 154 NPC, квартету 36. Предлагается сохранить базу дуэта, но фиксировать командное вознаграждение: 40 XP/орган, 10/пакет, новинки 200/200/200/300/400/500, первая кровь 100, своевременный заказ 300. Личный вклад = командная награда / P, дробные остатки сохранять. Это осознанное изменение Confirmed v02, поэтому только предложение, не текущий расчёт. Состав на момент продажи больше не ускоряет/тормозит общий unlock.

2. **Слишком ранний каталог может открыть дорогую ветку до её обучения.** Предложенная нормализация снимает квартетный всплеск без увеличения solo-гринда. Цены навыков пока оставить 1 000/3 000, 500/1 000/2 000, 500/1 000/2 000; сначала тестировать нормализацию отдельно, не менять сразу обе стороны экономики.

Сохранить качество-независимые XP и предел насыщения −30% в первом тесте; не вводить второй денежный/XP штраф без данных. Для организации хранения предложить стартовую вместимость кулера **10 вместо 8**, чтобы один полный NPC + 2 крови помещался; цена **$1 000 без изменения**. Поэтому 10 слотов — только предложение удобства, не обязательное исправление экономики.

4. **Кровь до сложной операции может уменьшать итоговый доход.** Высокие шансы ранней смерти + длинная последовательная работа особенно бьют по соло. Если тест с фактической частотой заказов показывает рывки, пробный бонус **+100/игрока** (или **200 команде** при нормализации), не менять +25% денег, 48 часов и один активный слот. Предложения выше — независимые варианты. Основные таблицы §§3–9 используют только действующие цены/XP и явно обозначенные допущения. Таблицы альтернатив отдельно подписаны; спецификации не правились.
