# VOLUNTEERS ONLY — вид, звук, интерфейс и проверка производительности

Дата: 28.10.2026. Версия: v01. Дизайн/требования, без изменений игры.

## 2. Визуальное направление

Сохраняется One-Armed Robber-направление: объёмные низкополигональные формы, читаемые силуэты, сдержанные нарисованные текстуры, приглушённый цвет, умеренно тёмный дневной свет. Не возвращать яркую старую палитру и не добавлять шумную фотореалистичную грязь. Юмор идёт из поведения и физики, а не непрерывных заставок.

Районы различаются существующей архитектурой/растительностью/светом, не отдельными несовместимыми стилями. Согласованные туман +8%, функциональные неяркие лампы и профили травы 60/50/40 м сохраняются до целевого теста. Уровни/музыкальные события не меняют свет/погоду тайно. Для новых моделей/интерьеров соблюдается проектный порядок «референс → выбор владельца → текстуры → производство», без генерации ресурсов этой задачей.

Поверхности не плавают, дороги/берега соединяются без ступеней, растительность не закрывает обязательный путь. Перед изменением геометрии нужны проверенные ракурсы/утверждённая карта, а не только эта спецификация. Первый-person hands остаётся отдельной поздней задачей; их отсутствие не блокирует корректное физическое действие, подсказку и звук инструмента.

## 3. Звуковая иерархия, Proposed

| Приоритет | Слой | Назначение |
|---|---|---|
| 1 | Критическое действие/опасность и принимаемый телефон | Разборчивый результат/причина; информация не теряется под музыкой. |
| 2 | Близкие NPC и физические действия | Сопротивление, комическое исполнение, контакты, инструменты/пакеты/двери. |
| 3 | Бусик | Тяга/нагрузка/поверхность, торможение, двери, груз и пространственные реакции пассажиров. |
| 4 | Пространственное окружение | Лес/ветер/вода/город/базы, с расстоянием и затуханием. |
| 5 | Радио и редкие музыкальные акценты | Настроение, без постоянного закадрового трека. |

Proposed: при принятом звонке радио приглушается примерно на 8 dB плавно, после окончания восстанавливается за ~0,5 с. Звуки мира не замолкают полностью. Один близкий выразительный NPC-гэг может выделиться, но все персонажи не запускают одинаковые крики/джингл одновременно. Повторы коротких вариантов ограничены по событию/личности, не по каждому физическому кадру.

Телефонные голоса/манера персонажей и простор громкой связи до 10 м сохраняются. Личный разговор не слышен всей карте; громкая связь не включается при передаче роли автоматически. NPC используют принятую стилизованную речь/фонетику и читаемые субтитры/реакции, не реалистичную медицинскую озвучку.

Звуковые игровые события авторитетны: одно столкновение/успешный шаг/продажа даёт один значимый звук, а не один на каждого клиента. Локальная реакция UI может быть индивидуальна, но не порождать повторные награды. Тишина на расстоянии не означает, что NPC перестал существовать.

## 4. Радио и события

Proposed: бусик имеет простое включение/выключение и громкость радио, одна текущая станция/позиция для этой машины. Слышимость пространственная; продолжение песни не привязано к открытому телефону. Игрок может выключить радио без отключения критических сигналов. Обычные внешние двери/окна не требуют новой дорогой симуляции акустики для первого прохода.

Редкие акценты: знакомство покупателя/базы, новый уровень, успешное завершение крупного сюжетного задания и финала. Они короткие, без обязательной музыки на каждую почку. Успех сделки прежде всего сообщает расчёт/чек/короткий звук. Нет новой музыкальной классификации «началась погоня» со своими полицейскими условиями — поступает уже существующий игровой сигнал.

Лес — ветер/растительность/редкие местные события; Хутор — двор/вода/хозяйственные звуки; Стройка — сдержанная работа существующих объектов; Rough/Downtown — различная плотность городской среды; долина — вода/ветер и локальный клубный источник. Это набор направлений, не утверждение новых животных, поездов, машин и толп в сценах.

Источники сначала искать среди уже лицензированной библиотеки проекта. Каждый новый файл требует подтверждённого происхождения/лицензии/атрибуции по правилам проекта. Эта спецификация не разрешает скачивать коммерческую музыку, оплачивать генерацию или копировать чужой саундтрек. В варианте без доступного лицензированного трека игра остаётся работоспособной с окружением.

## 5. Интерфейс и управление, Proposed

Меню: продолжить → пять миров/новая игра → подключение/хост по действующему сетевому контракту → настройки → выход. Переход/загрузка сессии явно показывает мир и хоста, не создаёт новый общий инвентарь. Игра не требует настройки классов.

HUD минимален: шесть карманов/активный инструмент, физическая подсказка действия, общий фонд/важная дельта, понятные состояния пациента/предмета по существующим спекам. Полный список задач/торговли живёт в телефоне. Не дублировать телефонную карту отдельным новым обязательным экраном и не превращать действующий фонд в два кошелька «карман/банк».

Ошибки показывают причину: шприц другой личности, не тот товар/качество/упаковка, недостаточно общих денег, занятая роль/устаревшая сумма. Состояния не передаются только цветом. Proposed: субтитры по умолчанию включены, масштаб текста/чувствительность/инверсия и переназначение действий доступны, подсказки показывают актуальные привязки. Удержания и короткие действия различимы визуально; нет обязательного дополнительного QTE для закрытия предупреждения.

Все подробные баннеры, 2,5-секундный сканер, личное чтение, история/напоминания, driver-safe показ и владение переговорами наследуются из PHONE, а не упрощаются этой заметкой. В активном кооперативе меню/телефон одного игрока мир не останавливают. Proposed: одиночное системное меню паузы может останавливать симуляцию/таймеры целиком; открытие телефона и разговор сами паузой не являются. Это пауза активного времени, не начисление офлайн-прогресса.

## 6. Настройки графики и производительность

Решение Феди 28.10 (заменяет запись 25.10): **начальный пресет по умолчанию — Low** (как у Вадима: W86GraphicsSettingsV01.Preset(0) и запасные значения в W86LookV01); игрок поднимает графику в меню Escape. Работа и проверка внешнего вида по-прежнему ведутся на максимуме (MSAA 8x и штатные отражения как верхний вариант). Настройки пользователя после явного выбора важнее начального значения.

Proposed: три понятных профиля Low/Medium/High и отдельные отражения, тени, сглаживание, дальности/растительность, разрешение/экранный режим, лимит кадров. Изменение пресета не меняет физику, места тайников, важную видимость интерактивных целей или число сохранённых значимых NPC. На слабом профиле можно уменьшать визуальное качество, но не удалять платный холодильник/улику/стяжку из геймплея.

Не объявлять минимальные требования по редакторским FPS. Проверочные конфигурации из источников: RTX 5070 Ti / Ryzen 7 7800X3D / 32 ГБ как машина Феди для максимума; RTX 3060 Ti / Ryzen 7 5700X как нижняя из упомянутых рабочих машин для отдельного замера. Это **не опубликованный минимум** и не рекомендация покупать ПК.

Proposed целевая проверка: standalone Windows x64, 1920×1080, 60 FPS (бюджет кадра ~16,67 мс) на выбранном профиле; отдельно хост и клиент, дневной/ночной Downtown, нагруженный бусик, несколько столов, разнесённые по карте игроки и реальные отражения. Записывать среднее/медленные кадры, CPU/GPU и память, точный профиль/железо/сборку. Лишь после результатов определить публикуемый минимум/диск/память/поддерживаемую ОС. В этом документе таких результатов нет.

## 7. Приёмка

| ID | Критерий |
|---|---|
| AV-01 | Сохраняется принятый стиль/палитра и читаемые силуэты, без возврата старой flat-only палитры. |
| AV-02 | В обычной игре нет обязательной непрерывной фоновой музыки; радио управляется отдельно. |
| AV-03 | Звонок/действие разборчивы поверх радио, без полного обнуления звуков опасности/мира. |
| AV-04 | Пространственная громкая связь/голоса не слышны по всей карте; выход/передача не включает их автоматически. |
| AV-05 | Один серверный исход не воспроизводит значимый звук несколько раз из-за повторного RPC. |
| AV-06 | Новые уровни/миссии не запускают обязательную заставку всем игрокам/водителю. |
| AV-07 | Актуальные кнопки/причины/субтитры читаемы, действие не распознаётся только по цвету. |
| AV-08 | Меню/телефон клиента не останавливают общий мир; solo-пауза останавливает все связанные таймеры согласованно. |
| AV-09 | High соответствует источнику; выбранный пользователем профиль не сбрасывается каждой загрузкой. |
| AV-10 | Low не удаляет геймплейные предметы/последствия и не ослабляет физику. |
| AV-11 | Музыкальные/звуковые ресурсы имеют документированное разрешение, не подразумеваются купленными этой спецификацией. |
| AV-12 | Требования к ПК не объявлены доказанными до standalone-измерений на конкретных профилях. |
