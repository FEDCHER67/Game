## 2. Основной цикл и доступность

Найти взрослого NPC → оглушить/связать общими средствами → физически перенести/погрузить → доставить на свою базу → выполнить доступную процедуру → упаковать при необходимости/сохранить качество → физически доставить товар покупателю/тайнику → подтвердить продажу → потратить деньги/XP. Тело, грязь и отходы разрешаются существующей системой уборки/утилизации, без автоматического исчезновения по чеку.

| Доступ | Единственный основной источник |
|---|---|
| Пространство районов | Мир физически открыт; уровень не закрывает дороги. |
| Почки/печень → глаза/мозг → сердце/лёгкие | Сюжетные знакомства с первым скупщиком → медиком → мафиози. |
| Мастерская | Доставка конкурента живым/связанным. |
| Следующие базы | Знакомство с первым скупщиком, далее деньги; предыдущую базу покупать не обязательно. |
| VIP | Купленная лаборатория + обычная сделка мафиози, нужный респект и свободный спецслот. |
| Формулы/дозировка/торг | Унаследованные покупки из свободного командного XP. |
| Дополнительные удобства ниже | Новый уровень + обычная денежная покупка, без новой валюты. |

Не вводятся новые классы игроков, обязательная профессия, растущие здоровье/урон, автоматическое увеличение качества или награды за высокий уровень. Соло сохраняет ту же систему, не требует отсутствующего второго игрока. Доход, физика NPC и условия открытия не становятся сложнее из-за присоединившегося друга.

## 3. XP: один учёт, разные назначения

Сохраняются `LifetimeTeamXP`, `FreeTeamXP`, личная статистика вклада и приобретённые навыки. Уровень вычисляется по пожизненному XP; трата свободного XP не понижает его. Личная статистика не является вторым тратимым кошельком.

| Событие | XP каждому присутствующему в сессии |
|---|---:|
| Проданный органный предмет | 20 |
| Порция крови, включая шприц | 5 |
| Первая кровь, дополнительно один раз на мир | 50 |
| Первый вид: почка/печень/парные глаза | +100 |
| Первый вид: парные лёгкие/сердце/мозг | +150/+200/+250 |
| Своевременный спецзаказ, сверх товара | +150 |

Команда получает сумму начислений присутствующим. Это уже выбранное правило: при одинаковой продаже XP команды соло/вдвоём/вчетвером различается; денежная сумма не умножается. Не нормализовать XP по N молча. Первый вид/кровь отмечается один раз на командное сохранение; в партии нового вида только первая единица получает бонус. Получение органа, упаковка, перемещение, загрузка, получение пустого шприца и восстановление чека XP не дают. Поручение механика и курьер не получают нового миссионного XP. Ruined и неуспешная продажа не оплачиваются XP.

Старые цены навыков сохраняются: дозировка 500/1 000/2 000 XP, формулы 1 000/3 000 XP, личные ранги торга 500/1 000/2 000 из общего свободного XP. Дополнительный личный ранг одного игрока не выдаётся автоматически всем. Формула открывает покупку запаса, а не бесплатный препарат. Пример защиты: потратив 500 из 650 XP, имеем 150 свободных и 650 пожизненных, не 150 для уровня.

## 4. Proposed: четыре уровня первого прохода

| Уровень | Пожизненный XP команды, накопленный | Дополнительный доступ |
|---|---:|---|
| 1 — Начало | 0 | Весь уже согласованный базовый цикл/сюжет, без новых ограничений. |
| 2 — Освоились | 500 | Покупка устройства прямого сбора крови в пакет, $1 500. |
| 3 — Налаженная работа | 1 500 | Покупка быстросъёмного механизма стола, $2 000. |
| 4 — Подпольный цех | 3 500 | Покупка упаковочного рабочего места, $2 500. |

Это три конкретных необязательных удобства, а не пустое бесконечное дерево. Ранее первые две позиции были резервом OPERATIONS T-13/экономики до появления функционального контракта; данный раздел и дополнение операций задают такой контракт. Новая третья цена Proposed. Покупка возможна только после доступности работающего предмета/адаптера; в сборке без него кнопка недоступна с причиной, деньги не списываются. Прежние нож/пила/холодильники/столы/базы не блокируются этими уровнями.

Уровень открывает предложение, не выдаёт предмет бесплатно и не расходует XP. Устройства покупаются за общий фонд, доставляются по обычным правилам на выбранную базу. Их несколько экземпляров допустимы, если есть место и деньги. Инициатор — любой участник. Достижение порога 500/1 500/3 500 фиксируется в той же транзакции, что XP; уведомление не является вторым событием начисления. На пороге нового уровня нет дополнительной денежной премии.

Proposed функции: прямой сбор убирает отдельный перенос порции в пакет, но сохраняет индивидуальный шприц/пакет/счётчик крови; быстросъём сокращает снятие четырёх креплений одним управлением, не ставит их бесплатно; упаковочное место выполняет последовательную упаковку физически загруженных предметов с настоящими пакетами. Детали — [операции и базы](OPERATIONS_BASES_INTEGRATION_SPEC_2026-10-28_v01.md). Ни одно устройство не лечит качество, не охлаждает и не создаёт органы.

После уровня 4 XP продолжает расти и тратиться на существующие навыки; дальнейших фиктивных наград нет. Непрочитанное уведомление не мешает покупке открытого оборудования. Поздний участник получает состояние мира, а не новые предметы/XP за пропущенные продажи.

## 5. Темп и проверка

Пороги — Proposed, не расчёт длительности кампании. Уже утверждённые цели экономики: полезная первая покупка обычно за 2–3 удачных цикла, крупная ранняя за 5–8; это не гарантии при каждом качестве. Проверка уровней должна учитывать число игроков, новинки, трату XP на конкурирующие ветки и реальное число продаж.

Контрольные примеры: повторный ранний NPC с тремя органами и двумя порциями крови даёт 70 XP одному игроку, командный итог 70/140/280 для 1/2/4 участников. Поздний полный набор семи предметов и двух порций — 150 на игрока, командно 150/300/600. Не возвращать старую модель восьми органов. Бонусы новинок идут отдельно и только однажды.

При одинаковом стартовом прогрессе две покупки навыков конкурируют за один `FreeTeamXP`; проверять его атомарно. Уже достигнутый уровень сохраняется после найма сотрудников/покупки базы/смерти/ареста. Целостная загрузка более раннего мира может вернуть более ранний уровень вместе с XP, имуществом и всей историей; это разрешённый откат, не выборочное сохранение выгодных частей.

## 6. Свободная игра после Трамдуро

Confirmed Q2: событие успешного завершения финальной миссии переводит этот же мир в постсюжетный режим. Оно приходит из отдельного контракта финальной миссии; здесь не придумываются способ захвата, обязательность всех VIP или новая кульминация.

Сохраняются имущество, фонд, сотрудники, уровни, NPC/предметные последствия, обычные продажи, незавершённые разрешённые заказы, время и карты. Уникальные четыре VIP, курьер и прочие completed-флаги не сбрасываются; Трамдуро не появляется вторым ради ещё одного финального чека. Невзятые уникальные задания можно выполнить, если их цели по авторскому контракту доступны. Обычное восстановление населения не возвращает сюжетную цель, помеченную окончательно resolved.

Proposed: короткое пропускаемое уведомление о завершении истории и кнопка продолжения; после него обычное управление, без нового платного режима/автоматического New Game+. Итоговая запись в истории одноразовая. Чужое личное закрытие телефона не возвращает команду к финалу.

Полицейская/государственная реакция не обнуляется окончанием истории; её продолжение обязан выдать владелец финальной/полицейской спецификации. Не закреплять вечную неизбежную погоню без возможности продолжать выбранную свободную игру; конкретный выход из чрезвычайного события — зависимость финала, а не новый закон этой спецификации.
