## 2. Как сделать (предложение Claude)

- Не новая система: готовая толпа Феди (CrowdDirector / CrowdWalker / CrowdData). Лесу нужны: маршруты-петли по тропам и холмам, точки-тайники как POI с действиями, точки входа/выхода закладчиков на краях леса, спавн наркоманов вне камеры.
- Каждая линия маршрута проверяется по карте: не ближе 1,2 м к стволу, камню, бревну, не по воде и болоту, уклон не больше ~25°.
- Действия у тайника — это «активности» POI (вход, цикл, выход), как скамейка или курилка в городе.

## 3. Анимации

Готовые: Walk, Idle_Stand, Idle_Bored, Idle_Variant_A/B, Stagger, BeachLie (лежание), BenchSit (сидение на бревне), Chat.
Новые (Claude, Blender, на скелет SausageBuddy), утверждено 28.10. Все — максимально угарные, в духе готовых клипов (Cop_Trip, Escape_Scramble, Flee_Panic_Run, Struggle_Carried): преувеличенные позы, инерция, «резиновость».

## 4. Приёмка

- 10 минут в лесу без игрока: ни одного столкновения, застревания, хождения по кругу, NPC в дереве или в воздухе.
- Закладчик доходит до тайника, кладёт (свёрток виден), уходит и исчезает вне камеры.
- Наркоман находит свёрток, колется, валяется, потом (см. §5) встаёт или исчезает.
- У притона 2–3 наркомана живут без сбоев.
- FPS в лесу не падает заметно (замер до и после).

Это логика леса как биома: наркоманы и закладчики живут в основном в лесу (Вадим 28.10), в других районах их мало или нет.

## 5. Поведение: здраво и дёшево (решает Claude, Вадим 28.10: «на своё усмотрение, главное без хуйни и без просадки FPS»)

### 5.1 Цикл наркомана
Тяга -> идёт к тайнику, где ЕСТЬ свёрток и никто его не занял -> роется -> нашёл -> идёт колоться -> укол -> отключка 80–90 с (разброс ±10 с) -> встаёт -> снова тяга.
- Притонный (2–3 места у костра): нашёл дозу -> возвращается в притон -> колется у костра.
- Бродяга: нашёл дозу -> отходит недалеко на свою точку отдыха (бревно, корни дерева, полянка; не на тропе) -> колется -> валяется.
- Свободных свёртков нет -> медленно бродит по петле тропы и раз в 30–60 с проверяет случайный тайник (Stash_Search без находки: развёл руками). Не толпятся: один тайник = один NPC.
- Притон заполняется сам: если место у костра пустое (наркомана убили/поймали), следующий бродяга с дозой займёт его.

### 5.2 Цикл закладчика (Вадим 28.10: живут в лесу, из леса не выходят)
Обход тайников (1–3 ПУСТЫХ, по пути) -> гуляет по лесу / стоит, озирается на своей точке 40–90 с -> новый обход -> ...
- Из леса не уходят и ни у кого не закупаются. Игрок их видит в лесу.
- Для FPS: далеко от игрока и вне камеры закладчик может «спрятаться» (выключиться) и позже появиться вне камеры на другой точке; для игрока это выглядит как обычная жизнь.
- Баланс: свёртков в лесу одновременно не больше ~числа наркоманов + 1; закладчик кладёт только в пустые тайники и только если лимит не набран, иначе просто гуляет. Так тайники не переполняются, и наркоманы находят дозу в среднем за 1–2 мин.

### 5.2а Замена убитых
Убили или поймали наркомана (или закладчика) -> через 60–120 с новый появляется в зоне, которую игрок не видит: вне камеры, дальше ~40 м от всех игроков, на точке спавна в глубине леса.

### 5.3 Правила «без хуйни»
- Одна точка (тайник, место у костра, точка отдыха) = один NPC: точку бронируют до подхода.
- Ложатся и колются только на точках отдыха / в притоне / у тайника, никогда посреди тропы.
- Ходят только по проверенной сетке линий (тропы + несколько линий по холмам) и коротким проверенным отводам к точкам; при сборке карты каждая линия проверяется: >= 1,2 м от стволов, камней, брёвен, не в воде, уклон <= 25°.
- В болото заходят только по редкому событию (бродяга, ~1 раз за 15–20 мин, только если рядом нет другого NPC); остальное время болото — запретная зона.
- Убили / поймали -> NPC выходит из цикла, его точка освобождается, пул выпускает замену вне камеры через 60–120 с.
- Застрял (2 с без движения) -> обход в сторону -> снова путь; не вышло -> телепорт на ближайшую линию, только вне камеры.

### 5.4 FPS
- Решения по событиям и таймерам (пришёл, нашёл, проснулся), не каждый кадр.
- Близко (до ~40 м): полная анимация, CharacterController, разведение с соседями.
- Средне (40–120 м): анимация реже (Animator culling / пропуск кадров), движение по линии без физики, LOD1/LOD2 моделей (TASK-000909).
- Далеко или не видно: без рендера и аниматора, только логика (таймеры идут, позиция считается по линии).
- Тени только у ближних. Всего в лесу не больше ~12 NPC.
- Бюджет: NPC леса вместе < 1 мс CPU на кадр; замер до и после.
