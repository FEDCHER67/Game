# VOLUNTEERS ONLY — STYLE BIBLE v1 (вид карты)

**Рабочее название стиля:** «Воскресное утро в игрушечном постсоветском городке».
**Редакция:** v1 от 06.10.2026. **Автор:** Fable (арт-директор по виду карты). **Статус:** на утверждение Феде вместе с пробным кадром.
**Область:** всё, что видно на карте — земля, дороги, дома, деревья, кусты, трава, пропсы, свет и пост-обработка. **Не входит:** NPC (внешний вид и анимации — область Вадима), план карты (`ArtSource/References/Map/MAP_PLAN_*`, `map_plan_*.py`), геймплей.

Основание: аудит вида R01 v12 (35 скриншотов из `Map_Look_v12.unity`), референсы Феди `ArtSource/References/Map/REF_FEDYA_v14_map_v23.png`, `REF_FEDYA_v14_old_town_square.png`, `REF_FEDYA_v13_hamlet_forest.png`, `REF_FEDYA_v13_old_town.png`, принятые Tripo-пропсы (`ArtSource/Props/*-ASTRA-*/Previews`), код вида (`Assets/OnlyVolunteers/Map/Look/*`), генераторы китов (`ArtSource/Props/MAP_PROPS`, `STREET_KIT`, `VEHICLES_KIT`, `LANDMARKS`) и текстур (`ArtSource/Textures/Map/tools`).

Слова Феди, которые этот документ выполняет: «пока что это выглядит как нейрослоп, а нам нужно что-то всё ещё низкополигональное, всё ещё простое, но менее нейрослопное, чтобы оно выглядело как-то более по-человечески».

## 0. Как пользоваться документом

1. **Это закон, а не пожелание.** Каждое правило либо число (hex, метры, проценты, треугольники), либо проверяемое утверждение «да/нет». Если правило нельзя проверить — оно сюда не попадает. Раздел 12 перечисляет, какие проверки автоматизируются в `MapLookValidator`.
2. **Три фазы внедрения.**
   - **Фаза A — пробный кадр** (этот документ + два кадра «было/стало»): только глобальные константы и перегенерация деревьев. Разделы 9, 3.3, 2, 5.4, 7.5, 6.3. Ни один файл плана карты не трогается.
   - **Фаза B — раскатка по семействам** после «ок» Феди: деревья v02, кусты, текстуры без грязи, пропсы «пухлее», окна, вода.
   - **Фаза C — ночь** (отдельный профиль света) — после утверждения дневного вида.
3. **Правило локальных правок (слова Феди, 06.10.2026):** при дальнейших изменениях схемы карты не перерисовывать её целиком, а брать только один названный кусок — район или прямоугольник в координатах карты — и менять только его; всё остальное остаётся как было. Для этого документа это значит:
   - любая правка плана/дрессинга/вида оформляется как «район X» или «bbox (x0, y0)–(x1, y1) м» в системе координат `MAP_PLAN_R01` (0–972 × 0–672 м, ось Y вниз как на PNG);
   - вне названного куска байты json и пиксели PNG не меняются (проверка: diff json по id объектов, diff PNG по маске bbox);
   - в отчёте о правке всегда указан затронутый район/bbox.
4. **Ревизии не перезаписываются** (правило проекта): новая модель — новый номер (`TR_Birch_A_v02.fbx`, `MAP-TREES-001_v02.blend`), новая текстура — новое имя в манифесте, новая палитра — `Look_Palette_v2.png`.
5. **Что уже хорошо и не переделывается** (см. аудит, п. 3): процедурная геометрия домов (`ProceduralBuilding.cs`), все киты улиц/машин/ландмарков/заборов/гаражей/фонарей/пляжа, атлас вывесок, башня с часами, казино-корона, фонтан, рынок, NPC. Меняются цвет, свет, текстуры и силуэты деревьев — не содержание.

## 2. Палитра

### 2.1. Правила насыщенности и яркости (HSV, V и S в %)

| Семейство | Hue | S | V | Примечание |
|---|---|---|---|---|
| Стены (штукатурка, панель, дерево) | любой | 8–35 | 75–95 | Светлые. Кирпич заводской — исключение: S ≤ 60, V 70–78. |
| Наличники / тримы | тёплый | ≤ 8 | ≥ 92 | Всегда тёплый белый. Единственное исключение — промзона (светло-серый). |
| Крыши | любой | 20–60 | 40–55 | Темнее стены минимум на 25 % V. |
| Листва | 85–140° | 40–65 | 45–78 | Верх светлее низа на 15–25 % V. |
| Трава / земля | 80–100° | 45–55 | 60–80 | Один тон на зону, второй — только для тени леса. |
| Вода | 200–210° | 65–80 | 75–85 | Насыщенная. Только здесь и на акцентах допустима S > 70. |
| Небо | 205–215° | 30–70 | 85–95 | Градиент зенит → горизонт. |
| Асфальт / бетон | нейтр. | ≤ 6 | 42–50 (асфальт), 70–80 (бетон) | Светлее, чем сейчас; никогда не чёрный. |
| Акценты (вывески, неон, машины, площадка, тенты, корона казино) | любой | 70–100 | 60–100 | Единственные носители полной насыщенности. |

**Запрещено:** «кислотный зелёный» — любой цвет с Hue 70–110°, S > 70 и V > 80 (например `#7FFF00`, `#9CFF3B`, `#A4F53C`). Проверка: ни одна заливка листвы, травы, кустов не выходит за S 65 / V 78.

**Ярусы по яркости (жёсткое правило):** небо светлое → стены светлые → земля средне-светлая → листва средне-тёмная → крыши тёмные → вода насыщенная. Проверяемые пороги: крыша темнее стены ≥ 25 % V; листва темнее стены ≥ 15 % V; трим светлее стены ≥ 10 % V; земля светлее асфальта ≥ 20 % V.

**Счётчик цветов:** на всю карту ≤ 40 заливок из таблицы 2.2 плюс акценты 2.4. На один район — ≤ 3 цвета стен, 1 трим, ≤ 2 цвета крыш. Два соседних дома (общая граница участка или ≤ 12 м между фасадами) никогда не делят цвет стены.

## 3. Шейдинг

### 3.1. Принцип

Поверхность = **один плоский цвет** из книги образцов. Второй уровень — **мягкий градиент по вершинному цвету** (верх светлее / низ темнее) там, где объект большой и без него читается как картон: кроны, кусты, купола, цистерны, корона казино. Третьего уровня нет.

- Фотографических и фото-подобных текстур нет. Это включает процедурные текстуры, имитирующие фото: шум штукатурки, потёки, мох, трещины, лужи, лишайник, ржавые разводы.
- Текстура разрешена **только когда она несёт информацию** и только как «детальная карта» с контрастом ≤ 15 % по яркости: кирпичная кладка (ряды), черепица (ряды), доски (швы), панельные швы, фальцы листа, плитка тротуара (швы), ряды брусчатки. Никаких пятен поверх.
- Один **общий палитровый атлас** `ArtSource/Textures/Map/palette/Look_Palette_v1.png` (256 × 256, сетка 16 × 16 ячеек по 16 px): строка = семейство (ground / wall / trim / roof / opening / foliage / water / accent), ячейка = образец из 2.5. Строки 8–11 — вертикальные градиенты для листвы (leaf_light → leaf_dark), хвои (pine_light → pine), кустов и воды. UV ставится в центр ячейки; для градиентных строк V кодирует высоту внутри объекта (0 = низ, 1 = верх). Генерируется скриптом из JSON раздела 2.5, руками не рисуется.
- **Запечённое AO через вершинный цвет** — только где помогает: под кронами (низ кроны ≤ −15 % V), у земли на стволах и столбах (нижние 0.3 м, ≤ −10 % V), под козырьками и балконами (≤ −12 % V), в проёмах окон (откосы ≤ −8 % V). Больше нигде. Множитель хранится в вершинном цвете R (1.0 = без затемнения), шейдер умножает на него albedo.

## 4. Язык форм

1. **Один силуэт на объект.** На 50 м объект узнаётся по контуру без цвета (тест: рендер в один серый цвет на светлом фоне). На 100 м — различима категория (дерево / дом / фонарь / машина).
2. **Коренастость.** Пропорции слегка сжаты по вертикали и расширены по горизонтали относительно реальности: столб фонаря Ø ≥ 0.14 м, перила ≥ 0.08 м, водосток Ø ≥ 0.12 м, ветка ≥ 0.06 м у вершины. **Ничего тоньше 8 см** («пухлость» Tripo-пропсов). Текущие кобры, прутья площадки, рейлинги, CCTV-столб — утолщить ×1.5.
3. **Одна фаска.** У каждого твёрдого объекта — одна фаска на видимых рёбрах: пропсы 2–4 см (1 сегмент), здания 8–15 см на углах крыш/козырьков/цоколей (1 сегмент), машины 4–6 см (1–2 сегмента). Фаска даёт светлую кромку на солнце — это и есть «рисованность».
4. **Намеренная асимметрия.** На объект — **один** неслучайный асимметричный элемент: крыльцо не по центру, труба у края, одна ветка длиннее, одна лавка без рейки. Случайный джиттер вершин запрещён (max `jitter` 0.04 только на листве и кустах; у твёрдых тел 0). Случайный поворот — только у деревьев (yaw) и в подворотнях/промзоне (мебель, ±3–12°); на площадях, в старом городе и элитке мебель стоит по линиям.
5. **Три уровня деталей и не больше:** масса (коробка, крона) → вторичные формы (крыша, козырёк, балкон, ветки) → акценты (труба, вывеска, яблоко, фонарь на стене). Акцент ≥ 20 см, иначе он не читается и становится шумом. Нет четвёртого уровня (болты, царапины, надписи, кроме атласа вывесок).
6. **Плотность деталей:** на фасаде ≤ 1 акцент на 6 м длины; на дереве ≤ 5 долей кроны; на пропсе ≤ 3 цвета (основа + 1 акцент + металл/дерево).
7. **Бюджеты треугольников** (кит остаётся в тех же рамках, что сейчас; задача — не добавить, а убрать случайное):

| Семейство | Треуг. на ассет | Источник |
|---|---|---|
| Дерево | 400–1200 (крона из 3–5 долей по 80 тр., ствол + ветки ≤ 300) | `MAP-TREES` budget 1500 → фактически меньше |
| Куст | ≤ 400 | `MAP-BUSHES` budget 600 |
| Пучок травы / цветочное пятно | ≤ 24 / ≤ 60 | новый |
| Фонарь, скамейка, урна, знак | ≤ 600 | `MAP-LAMPS` 600–1300, STREET_KIT |
| Забор (модуль 2 м), гараж | ≤ 1200 / ≤ 1500 | `MAP-FENCES`, `MAP-GARAGES` |
| Машина | ≤ 3000 | VEHICLES_KIT |
| Ландмарк (башня-верх, корона, фонтан) | ≤ 4000 | LANDMARKS |
| Дом малый / functional / slab / tower | 2500 / 6000 / 12000 / 10000 | `BuildingStyle.TriangleBudget` — без изменений |
| Церковь, водонапорная башня | ≤ 8000 | спец-ветки `ProceduralBuilding` |

8. **Масштаб** (не меняется): человек 1.75 м, этаж 3 м, дверь 2.1 м, машина 4 м. Деревья — раздел 5.4. Только ландмарки (башня с часами, церковь, труба, водонапорка, вышки) пробивают линию крыш.

### 5.4. Высоты и правило «ниже конька»

- Уличное дерево (старый город, подворотни, элитка, хутор у домов) ≤ **8 м** = конёк двухэтажного дома (2 × 3 м + крыша). Проверка: высота дерева ≤ `h` ближайшего здания + 1 м, если здание ≤ 2 этажа; для панелек — ≤ 12 м.
- Лес: сосна 10–13 м, ель 8–11 м. Тополя 10–12 м (сейчас до 19.7 м). Ничто, кроме ландмарков, не выше 13 м.
- Поля: одиночные дубы до 10 м.
- Крона не пересекает стены: деревья ближе **1.5 м** к контуру здания (`fp`) отбрасываются билдером (`TerrainBaker.Trees`, тест по footprint) — это правка Unity-стороны, план не трогается.

### 7.3. Правило цветового разнообразия по районам

1. Стена = `district_walls[district][seed % n]`; если сосед (≤ 12 м) получил тот же образец — взять следующий по кругу.
2. Трим = `district_trim` (белый везде, кроме промзоны).
3. Крыша = `district_roofs[district][seed % n]`, независимо от стены.
4. Балконы панелек = `accent.balcony_*[seed % 3]` — один цвет на дом.
5. Гражданские (`civic`) могут брать wall_mint/wall_sky в любом районе; `neon` — только wall_plum.
6. Ландмарки (церковь, башня, водонапорка, вагон) — ручной выбор (сейчас в json), но тоже из книги образцов.

### 7.5. Как `ProceduralBuilding` потребляет палитру

**Фаза A — квантователь (рекомендовано для пробного кадра, план не трогается):**

// family: "wall" | "trim" | "roof". Reads the JSON block of section 2.5 (embedded copy in
// Assets/OnlyVolunteers/Map/Look/StyleBible_v1_palette.json). Picks the nearest swatch of

## 8. Пропсы

Киты (STREET_KIT, VEHICLES_KIT, LANDMARKS, FENCES, GARAGES, LAMPS, BEACH) уже в нужном языке; правила фиксируют его и закрывают расхождения.

1. **Цвета только из `MP_*` палитры** `_lib/mapprops.py`, а `MP_*` → образцы книги (таблица соответствий в 2.2; при расхождении значение `PALETTE` в `mapprops.py` приводится к образцу). Новых цветов в скриптах китов не бывает.
2. **≤ 3 цвета на пропс**: основа + 1 акцент + металл/дерево. Tripo-пропсы: 1 цвет + 1 акцент.
3. **Пухлость:** ни одного элемента тоньше 8 см (п. 4.2). Список на утолщение ×1.5: стрела кобры и консоль (`build_lamps.py`), стойки и перекладины площадки (качели, горка), рейлинги, водостоки, столб CCTV, ножки лавок, спинки знаков. Сетка-рабица — ячейка остаётся, проволока ≥ 2 см визуально (текстура с контрастом ≤ 15 %, не геометрия).
4. **Фаска 2–4 см на всех видимых рёбрах** (у китов есть; у Tripo-пропсов — скругления остаются как есть).
5. **Износ — геометрией и расстановкой, не текстурой:** сломанная рейка лавки, вандализированная остановка, открытый гараж без двери, наклонённый фонарь (≤ 6°), вагон со сдвинутой дверью. Потёков, ржавых разводов и грязи на пропсах нет; «ржавый» = образец rust заливкой.
6. **Текст — только атлас вывесок** (`sign_atlas`, Rubik / PT Sans Narrow). Плейсхолдер `SK_Signage` заменяется реальными досками из атласа. Никаких надписей на пропсах помимо атласа.
7. **Неон** (`LM_Neon_*`): всегда на тёмной подложке (доска `#1E2A44`, 0.08 м толщиной, поля 0.15 м вокруг контура), эмиссия ×4, крепится на стену или на П-образную раму из `metal` — не стоит в траве (`bar_neon.png`).
8. **Труба стока** — rust `#8A5A3A` (сейчас `mat/pipe` `#9B5C36` + оранжевое солнце = самое насыщенное пятно пляжа).
9. **Пивот** на земле в центре основания; A/B варианты — разные пропорции, не масштаб; бюджеты по 4.7.
10. **Порядок расстановки:** на площадях, в старом городе и элитке мебель строго по линиям (без `Jitter` в `PropScatterer`); джиттер 3–12° остаётся только в подворотнях, промзоне, на хуторе. Машины — по полосам парковки.
11. **Конфликты размещения** (данные плана, флаг планировщику, не Unity): пальма сквозь крышу виллы и дуб в доме (`elite_blue2`), берёза в парковочном месте (`park_casino`), яблоня в стене бара (`church_front`), панели ограды, утопленные в склон (`elite_blue3` — панели должны следовать склону наклоном, не погружением). Правятся по правилу локальных правок — по одному bbox.

## 12. Проверки и принуждение

Правило, которое нельзя проверить, не правило. Что проверяется и чем:

| Проверка | Как | Инструмент |
|---|---|---|
| Все цвета стен/тримов/крыш после квантования ∈ книге образцов | сравнение hex материалов зданий с 2.5 | `MapLookValidator` (новая проверка `palette`) |

| Нет кислотного зелёного: все заливки листвы/травы/кустов S ≤ 65, V ≤ 78 | HSV материалов `mat/leaves/*`, `layer/*` | `MapLookValidator` |
| Ярусы яркости: крыша ≤ стена − 25 % V, трим ≥ стена + 10 % V | по материалам дома | `MapLookValidator` |
| Высота дерева ≤ лимита района и ≤ ближайший дом ≤ 2 эт. + 1 м | по `trees[].h`, `buildings[].h`, район по `districts` | `MapLookValidator` |
| Дерево не ближе 1.5 м к `fp` здания | геометрия | `TerrainBaker.Trees` (отбрасывание) + отчёт |
| Детальная карта: контраст ≤ 15 % | min/max luma детальной текстуры | `MapArtSetup.Detail()` assert |
| Smoothness ≤ 0.1 у всех материалов, кроме glass/water/metal/neon/marking | обход материалов | `MapLookValidator` |
| Shadow distance ≥ 200, fog start ≥ 500, vignette = 0, tonemap = Neutral | чтение ассетов | `MapLookValidator` (проверка `lighting`) |
| Ни один элемент кита тоньше 8 см | min габарит ограничивающих боксов частей | `mapprops.Family.finish()` validation (новое поле `min_member_m`) |
| `jitter` ≤ 0.04 | grep по `build_*.py` | ревью кода |
| Правка плана/дрессинга затронула только названный bbox | diff json по id, diff PNG по маске | скрипт `plan_diff.py` (новый, вне плана) |
| Ревизии не перезаписаны | имена файлов с номером версии | ревью |

Любая правка, нарушающая проверку, не идёт в сцену. Новый образец или исключение добавляются только правкой этого документа (новая редакция v1.x) с одобрения Феди.
