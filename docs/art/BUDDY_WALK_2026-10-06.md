# Sausage Buddy: отдельная ходьба — 06.10.2026

## Результат

Для Sausage Buddy A/B v04 добавлен самостоятельный цикл Walk. Обычная ходьба больше не использует замедленный Panic_Run_Loop. Авторские исходники: `ArtSource/Characters/SAUSAGE_BUDDY_01/Animations/Locomotion_v01/Walk_v02.blend` и `Walk_v02.fbx`; детали происхождения и измерения — в README.md и validation_v02.json той же папки. Исходные A/B v04 не изменены.

- 30 кадров/с; кадры 1–21, последний повторяет первый; цикл 0,666667 с.
- Номинальная скорость 1,5 м/с. Попеременная опора, короткая двойная опора, подъём переносимой стопы до 6 см, спокойный противоход рук.
- In-place: горизонтального перемещения корня нет. Старые Idle, Panic_Run_Loop и Panic_TurnFlee сохранены.
- В Blender максимальная погрешность положения опорной подошвы — 0,525 мм; это измерение исходного цикла, а не гарантия контакта на любом игровом рельефе.

## Подключение в Unity

Runtime FBX: `Assets/OnlyVolunteers/Characters/SausageBuddy/Animations/Walk_v02.fbx`. Generic, Copy From Other Avatar A, Preserve Hierarchy, без сжатия, Loop Time включён. Без Preserve Hierarchy Unity удаляет уровень `Buddy_Rig_Mixamo65` из путей кривых. Проверены все 660 кривых на обоих префабах: отсутствующих путей — 0.

Общий SausageBuddy_Greybox.controller сохранён с прежним GUID `d8645f8f609119a47864f840421a0401`; к существующим состояниям добавлен Walk. Установщик `Tools > Only Volunteers > Characters > Install Buddy Walk` и сборка префабов сохраняют существующие состояния.

- GreyboxWalker: WASD — Walk, Shift — Run; при остановке Idle.
- CrowdWalker: обычный маршрут — Walk, бег с сообщением о происшествии — Run.
- GreyboxNpc: испуг — Run; блокировка движения — Idle.
- PoliceOfficer: медленное передвижение — Walk, быстрое — Run. Сохранён отдельный множитель темпа толстого полицейского.
- Темп выбирается по фактической горизонтальной скорости CharacterController: скорость / 1,5 для Walk и скорость / 3,2 для Run. Переходы по 0,15 с. Темп ограничен защитными пределами; для быстрого полицейского верхний предел допускает его текущие 7,4 м/с.

## Проверка

Unity 6000.5.11f1: компиляция и Play без ошибок. Проверка не ограничивалась входом в Play: кадры и время игры продвигались.

В Map_Look_v12_Play с 61 NPC проверен реальный CrowdWalker:

| Ситуация | Состояние | Скорость движения | Темп клипа |

| Маршрут | Walk | 1,488 м/с | 0,992 |
| Пауза | Idle | 0 | 1 |
| Игрок подходит сзади | Run | 4,498 м/с | 1,406 |
| Угроза убрана, NPC успокоен | Walk | 1,489 м/с | 0,993 |

Пауза/угроза задавались только в Play; изменения карты не сохранялись. JSON фактических значений — `Working/Reviews/BuddyLocomotion_v01/UnityValidation.json`. Снимок с карты — `Map_NPC_Walk_v02.png` там же.

В отдельной обзорной сцене проверены оба варианта, цикл Idle → Walk → Run → Walk → Idle, переключение авто/ручного режима, включение CharacterController и камеры, возврат в авто. Ручное нажатие WASD/Shift и субъективное ощущение управления пользователем ещё не проверялись. Сетевой игрок не изменён.

## Посмотреть

Открыть `Assets/OnlyVolunteers/Scenes/Map/Buddy_Locomotion_v01.unity` и нажать Play. Сначала оба персонажа показывают цикл автоматически.
