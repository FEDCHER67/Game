## 2. Тексты

Созданы 73 пары RU/EN в 30 ситуациях. Все новые ID стоят первым блоком CAPTURE_MESSAGES_DRAFT.md. JSON сохраняет ровно поля buyer_messages: id, buyer, situation, ru, en, placeholders. Префикс capture.* — строчные слова через точки, варианты _01/_02. Поле buyer: NPC/SYSTEM обозначает говорящего; нового покупателя тел нет.

| Состояние | Варианты / правило |
| --- | --- |
| Проснулся в кузове | 3 стука, 3 просьбы, 3 угрозы/жалобы |
| Руки / ноги / обе пары | По 3; руки не обещают остановку бега, ноги — прыжки, обе — гусеница |
| Мешок | 3 приглушённые, 3 дезориентация, 3 после столкновения |
| Мешок + ноги | 2 попытки снять, 2 прыжки, 3 падения; руки свободны, мешок остаётся |
| Мешок + руки / полный буррито | По 2 дополнительных |
| Сон / пробуждение после наркоза | По 4 |
| Тесно / дёргается / труп / нет стяжек | 3 / 3 / 2 / 3 |
| Связать руки/ноги, срезать, мешок | 6 prompts с локализованной кнопкой {interact} |
| Облако / шапка / очки | По 3; ещё 1 системная подсказка для обоих упавших аксессуаров |

Proposed подача: выбирать без немедленного повтора, не накладывать несколько реплик одного NPC; числовой cooldown не выбран. Сон подавляет бодрые реплики; мешок требует приглушения. Аксессуары комментирует только бодрый NPC с соответствующей вещью; системная подсказка «шапка и очки» — только при падении обоих. Одежду полностью закрывает облако; после него тот же NPC в пациентских шортах. Аксессуары остаются мусором/уликами без денежного лута.

Отказ «дёргается» относится к забору крови, а не к запрету всех действий с бодрым NPC. Отказ для трупа приоритетнее движения. Реплики не обнуляют остаток наркоза, не называют реальных препаратов/доз и не обещают безопасную инъекцию. Срезание требует допустимого ножа/скальпеля; отдельный полевой нож пока не решён.

## 5. Допущения симуляции

Все отсутствующие в спеках сценарные параметры ниже — proposed, не статистика игры.

- Два режима: Хутор — 2 почки + печень и 2 пакета крови; Даунтаун — 8 органов и 2 крови. Тип обычный, без сдвигов органов. Каждый выход продан. Инструменты, рабочая база и кулер уже приобретены. Свободный денежный остаток 0; он копится только на кузов. Доходов от тела, карманов или аксессуаров нет.
- Capture §6: Хутор 75% Good / 25% Acceptable — proposed веса самой спеки; Даунтаун 50% Good / 50% Perfect — равные доли D9. Condition 85 — proposed сценарий, по D8 без потери. Condition 60 в чувствительности снимает ступень. Границы 75/50/25 не менялись. На каждый орган один штраф ступени с proposed вероятностью G30 40/25/20/20% для 1/2/3/4 игроков.
- Сохранён последовательный темп G30: proposed 30/24/20/20 с на орган; открытие живота +20 с, головы/груди по +35 с однократно. Это не замер и не модель параллельных зон. Две крови до операции; брюшные риски 30/40/50%, глаза 0%. T-03 для глаз проверяется отдельно. Первая потеря в теле через 85 с — proposed T-04 после confirmed грейса 45 с, затем шаг 40 с. Альтернатива — первая потеря через 45 с. Смерть не удаляет оставшийся товар.
- Извлечённый орган сразу охлаждается; доставка менее 25 минут при нулевом накопленном прогрессе. Кулер имеет подтверждённые 8 слотов; кровь едет отдельно и холода не требует. Для накопленной партии нужен соответствующий объём хранения. Ожидание NPC, маршрут и сохранность condition не измерены; вместимость кузова не останавливает пробуждение или порчу очереди.
- Транспортная политика proposed: руки + ноги на каждого NPC, 2 × $5 = $10 стяжек. Мешок в основе отсутствует; чувствительность добавляет proposed $5. Наркоз в пути не добавлен — NPC едет связанным. За столом расход initial-запаса считается ядром G30 до первой смерти. Повторные применения — упрощение денежного расхода, не инструкция вводить полную порцию поверх остатка.
- Прямые расходы G30: пустые пакеты крови, номинально потраченный initial-запас, один мусорный пакет $5 на NPC (последнее proposed; это мелкий мусор, не вместимость для тела). Обычных органных пакетов нет. Свет: confirmed $50/Хутор, $200/Даунтаун за сутки 45 активных минут; делится на proposed 3 NPC за этот срок. Улучшение не получает авансом ускорение оборота.
- Запасы амортизированы по ожидаемому расходу. Целые закупки запаса $200 и текущие остатки могут сдвинуть порог. Разовый резерв и стоимость первоначального оснащения не спрятаны в марже; таблица начинается с уже работающего бизнеса.
- Основная таблица: консервативный stress, все органы на подтверждённом полу насыщения 70%. Это не цена первого органа дня. Кровь не насыщается. Респект 2, навык торга 0: одна безопасная попытка, при отказе принять базу — proposed встречная цена; ожидаемый множитель 1.035. Реальный рост респекта не симулируется. Отдельно проверен нулевой торг.
- Деньги не умножаются на игроков. Отличия составов только из proposed скорости/ошибок. XP соответствует BUYERS v02, но кузов покупается за деньги. Персонал/комиссии, новые базы, другие покупки, аресты, пропуски встреч и потерянный товар исключены: частоты не заданы.
- Порог N = ceil(цена / ожидаемая чистая маржа). Это арифметика средних, не медиана случайной игры. L1 = ceil(A/M), L2 отдельно = ceil(B/M), оба = ceil((A+B)/M). После L1 остаток сохранён, дополнительных NPC = Nоба − NL1. Продажа означает физический предмет, не встречу/группу: 5 продаж/NPC в Хуторе, 10 в Даунтауне. Один предмет учитывается один раз.

## 8. Вывод и открытые вопросы

Предложение $2 500 + $5 000 проходит грубую проверку на исходных ценах и capture-качестве: несколько ранних успешных NPC либо короткая покупка на развитой базе. Это удобство после оснащения, не самостоятельная поздняя денежная цель. Падение condition удлиняет путь; сначала проверить состояние/очередь, затем править цену. Баланс не объявляется утверждённым.

- Утвердить ли $2 500/$5 000, последовательность и телефонный канал? Должен ли последний уровень быть поздней денежной целью, если полные наборы делают его доступным быстро?
