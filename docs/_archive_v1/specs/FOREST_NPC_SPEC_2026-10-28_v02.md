# Лес W86: жизнь NPC — спецификация v02, 2026-10-28

Черновик с Вадимом (grill-me). Основа: FOREST_SPEC_2026-10-27_v01, NPC_BEHAVIOUR_SPEC_2026-10-21_v07, канон пролога (CITY_MAP_REFERENCE_SPEC §2, BUYERS_SPEC: учебный шприц C01).
Этап 1 — «внутренний мир без игрока»: NPC игрока не замечают и не убегают, просто живут. Реакции на игрока — следующий этап.

## 1. Решено

| # | Решение |
|---|---|
| F-NPC-01 | В лесу одновременно 8–10 NPC: 3–4 закладчика + 5–6 наркоманов. Плюс 2 обдолбанных наркомана лежат в вагоне с начала игры (пролог). |
| F-NPC-02 | Ходят по тропам и немного по холмам и лесу, но только по заранее проверенным линиям: в деревьях, камнях, брёвнах застревать не могут. |
| F-NPC-03 | Закладчик приходит с края леса (дорога / тропа из Хутора), обходит 1–3 тайника: присел, спрятал 3–5 с, озирается, уходит и исчезает вне камеры. |
| F-NPC-04 | Наркоман бродит пошатываясь, подходит к тайнику, присел, роется, нашёл дозу, колется шприцом и валяется. Наркоманы НЕ курят. |
| F-NPC-05 | Закладчик и наркоман не связаны: тайники — общие точки, оба ходят к ним в разное время. |

| F-NPC-08 | Притон: 2–3 наркомана у кострища колются шприцами, один валяется «в приходе». Не курят. |

| F-NPC-11 | Двое в вагоне: лежат в углу вагона, один прижался к стене, другой на полу. Не встают, пока их не тронут. |
| F-NPC-12 | Наркоман после укола валяется 100–120 с, потом встаёт и снова бродит. |

| F-NPC-14 | Тайников 8–10 по всему лесу: пни, дупла, камни, корни. |

| F-NPC-10 | Никаких багов толпы: NPC не сталкиваются, не ходят кругами друг в друга, не застревают (готовая система толпы Феди: разведение, обход встречных, анти-застревание). |

## 2. Как сделать (предложение Claude)

- Не новая система: готовая толпа Феди (CrowdDirector / CrowdWalker / CrowdData). Лесу нужны: маршруты-петли по тропам и холмам, точки-тайники как POI с действиями, точки входа/выхода закладчиков на краях леса, спавн наркоманов вне камеры.
- Каждая линия маршрута проверяется по карте: не ближе 1,2 м к стволу, камню, бревну, не по воде и болоту, уклон не больше ~25°.
- Действия у тайника — это «активности» POI (вход, цикл, выход), как скамейка или курилка в городе.

## 3. Анимации

Готовые: Walk, Idle_Stand, Idle_Bored, Idle_Variant_A/B, Stagger, BeachLie (лежание), BenchSit (сидение на бревне), Chat.
Новые (Claude, Blender, на скелет SausageBuddy), утверждено 28.10. Все — максимально угарные, в духе готовых клипов (Cop_Trip, Escape_Scramble, Flee_Panic_Run, Struggle_Carried): преувеличенные позы, инерция, «резиновость».

| Клип | Что происходит |
|---|---|
| Junkie_Walk | Упоротая походка: шарканье, качка, ноги заплетаются, иногда спотыкается и ловит равновесие руками. |
| Stash_Place (вход/цикл/выход) | Закладчик сел на корточки, сунул свёрток в пень/камень, прикопал ногой, дважды резко оглянулся. |
| Stash_Search (вход/цикл/выход) | Наркоман роется руками, как собака, нюхает землю, вскакивает с находкой и прижимает её к груди. |
| Inject | Закатал рукав, уколол, закатил глаза, медленно оседает и падает назад. |
| High_Lie (цикл) | Лежит звездой, дёргает ногой, «гребёт» руками по воздуху. Тот же клип у притона и у вагонных (у стены — сидячий вариант Wagon_Slump). |
| Wagon_Slump (цикл) | Привалился к стене вагона, голова болтается, рука вяло отмахивается от мух. |
| Paranoid_Look | Резкие повороты головы, приседает на полусогнутых; закладчик в пути. |
| Bog_Sink | Наркоман в трясине: удивлённо машет руками и уходит вниз. |

## 4. Приёмка

- 10 минут в лесу без игрока: ни одного столкновения, застревания, хождения по кругу, NPC в дереве или в воздухе.
- Закладчик доходит до тайника, кладёт (свёрток виден), уходит и исчезает вне камеры.
- Наркоман находит свёрток, колется, валяется, потом (см. §5) встаёт или исчезает.
- У притона 2–3 наркомана живут без сбоев.
- FPS в лесу не падает заметно (замер до и после).

## 6. Порядок работы

1. Анимации в Blender: превью-гифки каждого клипа Вадиму, правки, его «да».
2. Маршруты-петли и тайники в лесу по плану, проверка линий (нет деревьев, камней, воды).
3. Подключение к толпе Феди: POI тайников, свёрток, вагонные, притон, болото.
4. 10-минутный прогон без игрока по приёмке §4, замер FPS, сборка.
