# Текстуры карты (генераторы)

Процедурные тайлящиеся текстуры для финального вида карты: фасады, окна, крыши, покрытия, вывески. Стиль — слегка мультяшный постсоветский город: крупные мягкие пятна цвета, без фотошума. Базовые море, песок, земля, трава, асфальт, бетон, кора и листва делаются в ветке `cloud/map-props` и здесь не повторяются.

PNG в репозиторий не коммитятся (LFS-загрузка заблокирована; `*.png` и `_fonts/` в `.gitignore` этой папки). Здесь лежат только скрипты, этот README и `map_textures_manifest.json`.

## Как сгенерировать

Нужны Python 3.10+, numpy и Pillow. Из корня репозитория:

```
pip install numpy pillow
python ArtSource/Textures/Map/tools/make_map_textures.py
```

Результат появится в `ArtSource/Textures/Map/<категория>/` (около 5 минут на 4 ядрах). Превью: `ArtSource/Textures/Map/previews/preview_all.png` и `preview_<категория>.png` (тайлящиеся текстуры показаны 2×2).

Полезные ключи: `--list` (список текстур), `--only имя1,имя2`, `--category facades,roofs`, `--offline` (без скачивания шрифтов), `--manifest-only` (только JSON).

Шрифты для вывесок — Rubik и PT Sans Narrow (OFL, Google Fonts) — скачиваются при первом запуске в `_fonts/`. Без сети используется DejaVu; тогда вывески выглядят иначе. При тех же шрифтах результат детерминирован.

## Что получается

У каждой текстуры: `_albedo` (sRGB, у декалей RGBA), `_normal` (OpenGL, как в Unity), `_roughness`, `_mask` (для URP Lit: R — металличность, G — запечённая AO, A — гладкость; в материале Smoothness Source = Metallic Alpha), у окон и вывесок ещё `_emission`.

| Категория | Текстуры |
|---|---|
| facades (2048) | панельная плита с окнами и балконами, силикатный кирпич, красный заводской кирпич, штукатурка ×6 оттенков со сколами, деревенская вагонка, рендер особняка с панорамными окнами, профлист |
| windows (1024) | атлас 16 окон 4×4: советские, ПВХ, деревенские со ставнями, заколоченное, разбитое, витрина, современное; днём и ночью |
| roofs (1024) | черепица, фальцевая кровля, плоская битумная кровля с заплатами, волнистый шифер |
| ground (1024) | плитка тротуара, брусчатка площади, бордюр, дорога с разметкой, старый асфальт с трещинами, гравий, грунтовая тропа, резиновое покрытие площадки; декали «зебры» и парковки |
| signage (2048) | атлас 12 вывесок: АПТЕКА, ПРОДУКТЫ 24 ЧАСА, БАР, КАЗИНО, ПОЛИЦИЯ, БОЛЬНИЦА, БАНК, КАФЕ, АВТОМАСТЕРСКАЯ, СУПЕРМАРКЕТ, НОЧНОЙ КЛУБ, БОУЛИНГ (почты нет) |

Размер тайла в метрах, режим повтора, координаты ячеек атласов и рекомендуемые настройки материалов Unity — в `map_textures_manifest.json`. В Unity импортировать только то, что реально используется (`Assets/OnlyVolunteers/...`). Это черновой набор: внешний вид нужно проверить в игре.
