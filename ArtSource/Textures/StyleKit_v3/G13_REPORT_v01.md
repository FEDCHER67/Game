## Processing and source exceptions

All final albedos replace source hue/saturation with the authoritative v2 palette chromaticity and retain compressed source luminance. Contrast is reduced by 45–88%, with toroidal smoothing. Albedo contains no multiplied AO or added grime. Grass uses lawn; dirt/sand use sand; gravel uses grey.light; mud uses wood.dark; bark/logs/planks use wood; water uses the unchanged palette water. Brick, paving, plaster, concrete and roofs use their named palette entries. Bitumen uses ink.light (#4A5058), a permitted dark-grey palette ramp.

Asphalt uses a wrapped 9-pixel median followed by a 12-pixel Gaussian filter. Brick keeps the full source X period and repeats a half-height source cycle twice vertically, doubling brick width/height to approximately 2:1. Normals use source height to verify Y orientation, explicitly select GL maps where provided, and reduce tangent slopes to 50%. The strongly sculpted slate source receives an additional relief cap of 19 degrees.

Masks are linear RGBA: R metallic, G restrained AO (0.90–1), B zero, A converted and restrained smoothness. The slate archive contains no AO, so it uses neutral white AO. Nonmetallic sources with no metallic map use zero. Painted metal limits exposed metal to 0.18; source corrugated metal retains its supplied metalness.

The roof is a dark-grey field with four roll courses across its 4-metre tile, three large angular patches, gentle normal seams and smoothness variation. Logs have horizontal courses and three sparse lengthwise grain bands per course; the separate end cap has exactly two rings. Both are original procedural outputs, with no downloaded substitute.

Grass 01 was fetched with an anonymous HTTP 200 response from the official page’s 1K link, without cookies, account credentials or payment. Its recorded custom licence is: “Royalty Free License: Free to use for all Commercial and Non-Commercial purposes.” It is not classified as CC0.

Not downloaded: 7a_rock_cliff / Stylized Rocks 002. Its official page and linked folder advertise only 4096×4096 maps; the brief permits 1K, or 2K if 1K is unavailable. No preview image or substitute texture was used. The two WE PAINT categories intentionally have no third-party downloads.

## Build and handoff

In Unity, invoke **OnlyVolunteers/Art/Build Style Kit v3 Materials**. The script imports albedo as sRGB, normal maps as OpenGL normal data, and masks as linear RGBA; enables repeat, mips and anisotropy ×4; binds the mask to MetallicGlossMap and OcclusionMap; and uses 1/metres_per_tile on every texture input (1 UV unit = 1 metre). Normal strength is already baked, so material BumpScale remains 1. Water is an opaque static URP Lit baseline; scrolling ripples, depth and shoreline foam are outside this material-building task.

The builder creates new numbered material versions if any target already exists and writes a new materials_built_vNN.json receipt with actual paths and GUIDs. Previous materials and receipts are preserved. The v01 partial PNG pass and complete v02 pass remain unchanged; only v03 is the final texture set. No commits, staging, deletion or WORK_SYNC edits were made.

To reproduce the same recipe into a new revision (example v04; v03 is immutable):
```powershell
python ArtSource/Textures/StyleKit_v3/tools/process_v3_v03.py process --revision 4 --source-revision 1
```
