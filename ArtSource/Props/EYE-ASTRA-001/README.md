# EYE-ASTRA-001 — глаз, предмет Item_Eye

## Готовая версия

- `EYE_ASTRA_001_v03.blend` — итоговый Blender-ассет с упакованной текстурой и камерой превью.
- `EYE_ASTRA_001_v03.fbx` — экспорт только предмета, со встроенной текстурой.
- `Textures/EYE_basecolor_v03.png` — локально запечённый цвет, 1024×1024.
- `Previews/01_front_v03.png` … `06_bottom_v03.png` — шесть ортографических проверочных видов.
- `Previews/07_hero_v03.png` — общий вид.
- `Validation/mesh_v03.json`, `fbx_roundtrip_v03.json` — проверки PASS.

550 треугольников / 277 вершин / 538 граней; один замкнутый меш. Все грани smooth. Разрывов, неманифолдных рёбер и граней нулевой площади нет. UV и текстура проверены повторным импортом FBX.

Стилизованный глаз: светлая оболочка, бирюзовая радужка, чёрный зрачок и короткий розовый выступ сзади. Матовый материал без фотореализма. Диаметр оболочки около 4 см, фронт по -Y, начало координат снизу. Масштаб можно согласовать с другими предметами при интеграции; префаб Unity этой задачей не создавался.

## Источники и стоимость

Комплект Tripo: FRONT `Rev01/01_front`, LEFT `Rev01/02_left`, RIGHT `Rev02/03_right` (точное отражение LEFT), BACK `Rev02/04_back`. Rev01 RIGHT отвергнут по масштабу и не использовался.

Изображения созданы в обычном ChatGPT. Одна генерация Tripo: Smart Mesh, multi-view, quads, цель 500, P2.0, количество 1, цена 100. Баланс 1080 → 980. Платных дополнительных операций не было. Все четыре слота очищены.

Исходный FBX сохранён неизменённым: `C:/Dev/Game/Working/Tripo/eye_tripo_base.fbx`. Результат генерации: https://studio.tripo3d.ai/ru/workspace/generate/a8005d2f-5e7d-47ad-b8c0-b3bd9473d32b .

Снижение полигонажа, устранение дефектов сетки и создание/запекание цвета выполнены локально в Blender 5.2.1 LTS. Подробности: REPORT.md, PROVENANCE.md. Не коммитили; WORK_SYNC.md не изменяли.

## Цветовые варианты v04

По запросу Феди «разклонь его и разного цвета радужку» создано пять новых вариантов: BLUE, GREEN, BROWN, GRAY, AMBER. Исходный TURQUOISE сохранён в v03.

Общая сцена: `EYE_COLOR_SET_ASTRA_001_v04.blend`, шесть независимых мешей с независимыми материалами, разложенных для сравнения. Превью: `Previews/color_set_front_v04.png`. Каждый глаз содержит 550 треугольников; 3300 — сумма шести экземпляров в сцене сравнения, не бюджет отдельного предмета. Надписи и свет — только вспомогательные элементы сцены.

Отдельные игровые ассеты: `Variants/v04/EYE_<BLUE|GREEN|BROWN|GRAY|AMBER>_ASTRA_001_v04.blend` и соответствующие `.fbx`. Каждый FBX содержит один глаз, origin и масштаб совпадают с v03. Текстуры 1024×1024 лежат рядом с вариантами, упакованы в Blender и встроены в FBX. Для каждого сохранены FRONT/HERO в Previews.

Изменены только цвета радужки и её тёмного ободка. Координаты вершин, топология, UV, smooth, белая оболочка, зрачок и задний выступ сохранены. Геометрия и UV до/после окраски совпадают по SHA-256, результаты записаны в `Validation/color_variants_v04.json`. Все пять FBX проверены повторным импортом: 550 треугольников, 538 smooth-граней, 0 неманифолдных рёбер, 0 граней нулевой площади, UV и текстура присутствуют — PASS. Сцена сравнения содержит шесть отдельных mesh datablocks.

Новых генераций Tripo нет, расход 0. Исходный FBX и версия v03 не менялись. WORK_SYNC.md не трогали, коммитов нет.
