# SK-BUS_STOP — автобусная остановка

Статус: **черновик облака v01, Федей не просмотрен.** В Unity не импортировано.

| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `SK_BusStop_Shelter` | 872 | 5.57 × 2.57 × 2.81 | Павильон 4.0 × 1.6 м: бетонный пол, задняя стенка — стальной каркас, синие нижние листы и стёкла, бетонные боковые стенки с цветными «мозаичными» полосами, крыша с оранжевым фризом, скамейка, табличка расписания. Справа спереди столб со знаком 5.16 (синий квадрат с автобусом). |
| `SK_BusStop_Shelter_Vandalised` | 952 | 5.57 × 2.57 × 2.81 | Для плохого района: выбитое стекло (осколки в раме), нет доски скамейки, граффити на боковых стенках, мусор и бутылка на полу. |

- Открытая сторона смотрит в −Y (к дороге). Пивот — центр основания на земле; столб знака стоит в (+2.9, −1.25).
- Табличка расписания на задней стенке — грань с материалом `SK_Signage`, ячейка `square_1x1` слот 0 (см. `../COMMERCE/README.md`).
- Коллайдер: box пола, box задней стенки, два box боковых стенок, box крыши; капсула столба.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/BUS_STOP/build_bus_stop.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-BUS_STOP_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.
