# SK-WRECKS — брошенные машины

Статус: **черновик облака v01, Федей не просмотрен.** В Unity не импортировано.

| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `SK_Car_Wrecked` | 1386 | 1.96 × 4.11 × 1.38 | Брошенный седан 70-х (пропорции «копейки»/«шестёрки», без логотипов и номеров): выцветший голубой, ржавые пороги и арки, мятые двери, спущенные шины, заднего левого колеса нет — барабан на кирпичах, разбито заднее левое стекло, треснувшая фара, капот приоткрыт, задний бампер провис, лёгкий крен влево. |
| `SK_Car_Burnt` | 1392 | 1.97 × 4.11 × 1.28 | Сгоревший кузов той же машины: только ржавчина/сажа/пепел, без стёкол и шин (сидит низко на голых дисках), каркас из стоек с просевшей крышей, внутри обгоревшие рамы сидений и руль, двери покороблены (передняя левая приоткрыта), капот вздут, крышка багажника приподнята, передний бампер висит. |

- Обе машины построены одной функцией кузова `sedan()`, нос смотрит в −Y. Пивот — центр основания на земле. Ширина по габариту включает арки, зеркало и отбитый кирпич/кучку пепла рядом.
- Коллайдер: один box по кузову (≈ 1.7 × 4.1 × 1.3) — box hull; для сгоревшей можно ниже (≈ 1.1 м), если нужно смотреть сквозь окна.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/WRECKS/build_wrecks.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-WRECKS_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
