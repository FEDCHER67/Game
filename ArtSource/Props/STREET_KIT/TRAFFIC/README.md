- Пивот — центр основания на земле. У шлагбаума — центр тумбы; стрела идёт вдоль +X, вилка-опора стоит в x = 3.8 м (входит в тот же меш, что и тумба).
- Стрела шлагбаума — отдельный дочерний объект `SK_ParkingBarrier_Boom`, пивот на оси шарнира (0, −0.235, 0.86); ось шарнира — Blender Y (горизонталь, вдоль проезда). Поворот на −90° вокруг Blender Y поднимает стрелу вертикально. Противовес и ступица крутятся вместе со стрелой.
- Знаки: серая стальная труба r 0.038 м высотой 2.5 м (у треугольников остриём вверх — 2.4 м, чтобы колпак не торчал над вершиной), бетонный «воротник» у земли, центр щитка на 2.2 м. Лицо знака смотрит в −Y, щиток ~8 см перед осью трубы, серая обратная сторона и две скобы.
- Рисунок знаков — геометрия, без текстур: цветные слои ступенями по 5 мм к −Y (элементы одного слоя дополнительно разнесены на 0.4 мм), z-fighting нет.
- Люк лежит на земле (низ z = 0, высота 2 см); в дорогу его можно утопить на 1–2 см.
- Коллайдеры: шлагбаум — box тумбы + box стрелы (на объекте стрелы) + capsule вилки; знак — capsule трубы + тонкий box щитка; гидрант — capsule; люку коллайдер не нужен.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/TRAFFIC/build_traffic.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-TRAFFIC_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
