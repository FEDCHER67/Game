## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/BENCHES/build_benches.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-BENCHES_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
