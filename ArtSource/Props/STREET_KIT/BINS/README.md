# SK-BINS — урны и мусорные контейнеры

Статус: **черновик облака v01, Федей не просмотрен.** В Unity не импортировано.

| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `SK_TrashBin_Concrete` | 222 | 0.54 × 0.51 × 0.69 | Советская бетонная урна-вазон, внутри чаша с мусором (бумага, бутылка). |
| `SK_TrashBin_Tipping` | 386 | 0.72 × 0.54 × 0.99 | Опрокидывающаяся урна между двумя трубами. Ведро — отдельный объект `…_Bucket`, пивот на оси (z = 0.78 м), вращение вокруг локального X. |
| `SK_GarbageContainer_Closed` | 578 | 1.62 × 0.95 × 1.17 | Уличный контейнер 0.75 м³: зелёный трапециевидный кузов, рёбра, цапфы для мусоровоза, колёсики, ржавый низ. Крышка закрыта. |
| `SK_GarbageContainer_Open` | 826 | 1.62 × 1.67 × 1.98 | Тот же контейнер, крышка откинута (−112°), переполнен пакетами и коробкой, один пакет на земле. |

- Крышка контейнера — отдельный объект `…_Lid`, пивот на задней петле (0, 0.43, 1.11); вращение вокруг локального X, отрицательный угол открывает. В Unity открытый вариант можно получить и из закрытого поворотом крышки.
- Пивот ассета — центр основания на земле; перед — −Y.
- Коллайдер: урны — капсула/цилиндр; контейнер — box кузова 1.4 × 0.8 × 1.1 м (+ box крышки, если она должна открываться физически).

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/BINS/build_bins.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-BINS_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
