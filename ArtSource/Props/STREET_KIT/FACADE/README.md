- **Пивот навесных деталей.** Стена здания — плоскость y = 0, деталь выступает в −Y (на улицу). Пивот (0,0,0) — точка крепления на стене: по центру по горизонтали, внизу детали. Балконы — низ плиты пола у стены; кондиционер и тарелка — низ кронштейна; водостоки — низ модуля, ось трубы в 0.14 м от стены (зазор 0.08 м); козырёк подъезда — земля у линии стены. В +Y ничего не заходит дальше 0.005 м (пластины и трасса в стену).
- Модуль этажа 2.8 м: балконы и водосток ставятся по вертикали с шагом 2.8 м (`Bottom` на земле, затем `Straight` с z = 1.0, верх — `Top`).
- Коллайдер: балконы — box плиты + box парапета (у застеклённого — один box по габариту); козырёк — box крыльца, box плиты и две капсулы стоек; мелочь (кондиционер, тарелка, водостоки) — один box или без коллайдера.

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/FACADE/build_facade.py -- --revision 1
```
