# STREET_KIT — уличный и дворовый набор (общие правила)

Стилизованный low-poly набор для постсоветского города: 9 семейств, 42 ассета, 192–1392 треугольника на ассет. Все модели строятся скриптами Blender Python (`bpy` 5.0.1 из PyPI или Blender 5.x, фоновый режим). Обзор и статус — `PRODUCTION_REPORT.md`; таблицы треугольников и команды сборки — в README каждого семейства.

| Папка | Что внутри |
|---|---|
| `BENCHES/` | скамейки: бетон+дерево (целая и сломанная), парковая |
| `BINS/` | урны (бетонная, опрокидывающаяся), контейнер 0.75 м³ закрытый/открытый |
| `BUS_STOP/` | павильон остановки (обычный и разгромленный) со знаком 5.16 |
| `PLAYGROUND/` | качели, горка, карусель, песочница с грибком, турник, выбивалка |
| `POWER_POLES/` | опоры 10 кВ (прямая, с подкосом) и 0.4 кВ, с сокетами проводов |
| `FACADE/` | балконы (открытый, застеклённый), козырёк подъезда, кондиционер, тарелка, водостоки |
| `COMMERCE/` | пустые вывески под атлас, газетный киоск, павильон банкомата |
| `TRAFFIC/` | шлагбаум, знаки 2.5, 2.4, 3.1, 1.17, 5.19.1, люк, гидрант |
| `WRECKS/` | разбитая и сгоревшая «классика» для плохого района |
| `_lib/` | `streetkit.py` — общая библиотека: палитра, примитивы, экспорт, проверка, превью |

## Соглашения (как у VAN-TIER0-ASTRA-001 и WATER-TOWER-ASTRA-001)

- Blender: Z вверх, метры, перед детали — −Y. FBX: `axis_forward=-Z`, `axis_up=Y`, `apply_unit_scale=True`, плоское (FACE) сглаживание, без анимации.
- Каждый ассет — корневая пустышка с именем ассета в (0, 0, 0) и дочерние меши. Пивот — центр основания на земле; у навесных на стену деталей — точка крепления на стене y = 0 (см. `FACADE/README.md`, `COMMERCE/README.md`).
- Подвижные части — отдельные меши с пивотом на петле/оси: крышка контейнера, ведро урны, сиденья качелей, диск карусели, стрела шлагбаума.
- Сокеты — пустышки `<Ассет>_SOCKET_*` (провода опор, точка взаимодействия у киоска и банкомата).
- Сетки замкнутые, нормали наружу, без вырожденных граней — это проверяет `validation_<Ассет>_vNN.json` (`all_checks_passed`). Бюджет 100–1500 треугольников на ассет целиком.
- Ревизии не перезаписываются: новая версия — `--revision N+1`; `--force` только для пересборки той же ревизии в черновике.

## Палитра и материалы

- Один общий материал **`SK_Palette`** на весь набор. Текстура `_lib/SK_Palette.png` — 8 × 4 ячейки по 16 px (128 × 64), генерируется скриптом. UV0 каждой грани стоит в центре ячейки её цвета, поэтому меши одного материала можно батчить.
- Тот же цвет записан в вершинный цвет `Col` (sRGB) — для шейдеров, которые берут цвет из вершин.
- Лицевые грани вывесок и таблички расписания — второй материал **`SK_Signage`** с UV в атлас 2048 × 2048; разметка — `COMMERCE/README.md` и `_lib/signage_atlas_layout.json`.
- Имена цветов: `PALETTE` в `_lib/streetkit.py` (бетон, дерево, краски, металл, ржавчина, стекло, знаковые красный/синий, сажа и пепел, автомобильные и т. д.).

## Импорт в Unity (рекомендация, не проверено)

- `SK_Palette.png`: Filter Mode = Point, Compression = None, Generate Mip Maps можно оставить (ячейки 16 px).
- Один URP Lit-материал `SK_Palette` (Smoothness ~0.15) на все модели; `SK_Signage` — отдельный материал с атласом вывесок.
- Model Import: Scale Factor 1, Convert Units включено, Import Normals = Import, материалы — Use External / переназначить на общие.
- Коллайдеры не входят в FBX: советы по каждому семейству — в его README.

## Сборка всего набора локально

```
pip install bpy==5.0.1          # Python 3.11
for s in BENCHES/build_benches BINS/build_bins BUS_STOP/build_bus_stop PLAYGROUND/build_playground POWER_POLES/build_power_poles \
         FACADE/build_facade COMMERCE/build_commerce TRAFFIC/build_traffic WRECKS/build_wrecks; do
  python3 ArtSource/Props/STREET_KIT/$s.py -- --revision 1 || break
done
```

Полная сборка с превью Cycles на CPU занимает около 15 минут; `--no-render` — секунды. В облаке .blend, .fbx и .png не отправлялись (загрузка LFS заблокирована): в репозитории только скрипты, README и JSON.
