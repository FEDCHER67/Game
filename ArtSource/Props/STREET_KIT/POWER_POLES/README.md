## Точки крепления проводов

Пустышки-дети корневого объекта, имя `<Ассет>_SOCKET_Wire_*`, стоят в канавке головки изолятора. Линия идёт вдоль оси Y (траверсы — вдоль X), провод между двумя опорами тянется от сокета к одноимённому сокету соседней опоры.

| Ассет | Сокеты (x, y, z), м |
|---|---|
| `SK_PowerPole_Concrete_10kV`, `…_Strut` | `SOCKET_Wire_A` (−0.85, −0.12, 9.155), `SOCKET_Wire_B` (0.85, −0.12, 9.155), `SOCKET_Wire_C` (0, 0, 9.93) |
| `SK_PowerPole_Wood_04kV` | `SOCKET_Wire_1` (−0.3, 0, 8.54), `SOCKET_Wire_2` (0.3, 0, 8.54), `SOCKET_Wire_3` (−0.3, 0, 8.04), `SOCKET_Wire_4` (0.3, 0, 8.04), `SOCKET_Wire_Drop` (0, −0.4, 7.57) — ответвление к дому |

Сами провода в набор не входят: их проще строить в Unity (LineRenderer или провисающая цепочка между сокетами).

- Пивот — центр основания стойки на земле. Изоляторы немного увеличены (мультяшно), чтобы читались с улицы.
- Коллайдер: капсула или box по стойке; подкос — отдельный box.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/POWER_POLES/build_power_poles.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-POWER_POLES_v01.blend`, `validation_SK_*_v01.json` (в них и координаты сокетов), `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
