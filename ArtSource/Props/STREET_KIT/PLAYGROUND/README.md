- Пивот — центр основания на земле. Перед — −Y.
- Подвижные части (отдельные объекты внутри ассета):
  - `SK_Play_Swings_SeatA` / `SeatB` (по 184 треуг.) — пивот на оси перекладины (∓0.65, 0, 2.25); качаются вращением вокруг локальной X. Рама `SK_Play_Swings_Frame` — 472 треуг.
  - `SK_Play_Carousel_Rotor` (558 треуг.) — пивот (0, 0, 0) на вертикальной оси; крутится вокруг Z. Статичное основание `SK_Play_Carousel_Base` — 92 треуг.
- Коллайдер: несколько box/capsule по трубам и сиденьям; для горки — box площадки + наклонный box ската; для песочницы — четыре box бортов и capsule стойки грибка.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/PLAYGROUND/build_playground.py -- --revision 1
```

Результат: `SK_*_v01.fbx`, `SK-PLAYGROUND_v01.blend`, `validation_SK_*_v01.json`, `Previews/v01/`, а также общая палитра `../_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.

Оси, материалы, палитра и импорт в Unity — общие для всего набора, см. `../README.md`.
