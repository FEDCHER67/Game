## Оси, пивоты, подвижные части

- Как во всём STREET_KIT (`../README.md`): Blender Z вверх, метры, **перед — −Y** (так у всех ассетов набора; FBX `axis_forward=-Z`, `axis_up=Y`). Корневая пустышка с именем ассета в (0, 0, 0) = центр основания на земле.
- `SK_CCTV_Wall` — навесной: стена = плоскость y = 0, пивот = низ настенной пластины, камера смотрит в −Y и наклонена на 15° вниз.
- Головы камер — отдельные дочерние меши `SK_CCTV_*_Head`, пивот на шарнире поворота (стена: (0, −0.22, 0.155); столб: (0, −0.35, 3.0)). Поворот вокруг локальной Z — панорамирование.
- Опоры трубы: труба идёт вдоль X; сокет `SK_PipeSupport_*_SOCKET_PipeAxis` — точка на оси трубы. Хомут сверху повторяет контур трубы d 0.8 м. Ставить через 4–6 м.
- Камни: выпуклые оболочки, плоское основание на z = 0; в Unity утопить на 5–15 % и свободно вращать/масштабировать (0.8–1.2).

## Материалы

- Всё, кроме лица пляжного щита, — общий материал `SK_Palette` (палитра `../_lib/SK_Palette.png` + вершинный цвет `Col`), как в наборе.
- Лицо щита (грань −Y доски) — второй материал **`SK_Text_NoSwimming`** с текстурой `SK_Text_NoSwimming_v01.png` 512 × 256: белое поле, красная рамка, красная надпись в две строки, пиксельный шрифт 5 × 7 (кириллица генерируется скриптом). UV грани — вся текстура. В Unity: Filter Mode = Point или Bilinear, Compression = None.
- Знак остановки, афиши, камеры — цветная геометрия без текстур (слои по 5 мм, без z-fighting).

## Коллайдеры (рекомендация)

Знак остановки — capsule трубы + тонкий box таблички; пляжный щит — box доски + 2 box столбов; опора трубы — один box по габариту ниже ложемента; тумба — capsule/cylinder; камни — convex mesh collider по самой модели; камера на столбе — capsule столба; настенная — без коллайдера; ящик — box 0.6 м.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/STREET_KIT/SMALL/build_small.py -- --revision 1
```

- Без превью (секунды): добавить `--no-render`. Полная сборка с превью Cycles на CPU — несколько минут.
- Результат в этой папке: `SK_*_v01.fbx` (13 шт.), `SK-SMALL_v01.blend`, `SK_Text_NoSwimming_v01.png`, `validation_SK_*_v01.json`, `Previews/v01/` (общий ряд и по кадру на ассет); общая палитра пишется в `../_lib/SK_Palette.png`.
- Существующую ревизию скрипт не перезаписывает без `--force`; новая версия — `--revision 2`. `--only SK_Rock_01,...` — отладка отдельных ассетов (без .blend).
- **.blend, .fbx и .png в облаке не отправлялись** (загрузка LFS заблокирована) — соберите локально, результат детерминирован.
