- **Пивоты.** Казино, кегля, шар, билборды, колонка — центр основания на земле/крыше, лицевая сторона −Y. Неон — навесной: стена y = 0, пивот на стене у низа трансформатора.
- **Части.** `<Ассет>_Mesh` — основное тело; `<Ассет>_Emissive` — лампочки/трубки/подсветка (казино, неон ×3, колонка); `<Ассет>_Poster` — лицевая грань постера (`LM_Poster`, UV 0..1); `LM_GasPump_Nozzle` — пистолет с пивотом у горловины держателя (0.47, −0.08, 1.22).
- **Сокеты.** `LM_GasPump_SOCKET_Interact` (0, −0.75, 1.0) — где стоит игрок; `LM_GasPump_SOCKET_Refuel` (0.9, −0.6, 0.6) — куда подъезжает горловина бака.
- **Коллайдеры (совет).** Казино — box по коробу; неон — без коллайдера; кегля и шар — capsule/sphere; билборды — box по щиту + capsule мачты; колонка — box по островку и корпусу.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1
python3 ArtSource/Props/LANDMARKS/VALLEY/build_valley.py -- --revision 1
```

Результат: `LM_*_v01.fbx`, `LM-VALLEY_v01.blend`, `validation_LM_*_v01.json`, `Previews/v01/` (общий ряд + по кадру на ассет). Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью; `--only LM_GasPump` — отладка одного ассета.
