# LM-OLD_TOWN — ориентиры старого города

Статус: **черновик облака v01, не просмотрен.** В Unity не импортировано.

| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `LM_MarketStall` | 796 | 2.70 × 1.61 × 2.62 | Деревянный прилавок 2.4 × 1.2 м: четыре стойки, красно-белый полосатый навес с фестонами (наклон вперёд), четыре ящика с «фруктами», весы, грифельная табличка цен. |
| `LM_ChurchBell` | 392 | 1.44 × 1.06 × 1.20 | Бронзовый колокол 1.06 м с золотой полосой у края, дубовая перекладина с железными хомутами и цапфами. Язык — отдельный объект. |
| `LM_OnionCupola` | 516 | 1.46 × 1.46 × 3.20 | Малая главка: белый постамент, восьмигранный барабан с арочными окнами, синяя луковица с золотым пояском и шейкой, золотой православный крест. |
| `LM_Fountain` | 828 | 5.08 × 5.08 × 3.22 | Восьмигранная чаша с бортиком-сиденьем 0.6 м, колонна с двумя чашами и навершием, четыре носика. Три водные поверхности — `LM_Fountain_Water`. |
| `LM_ClockTowerTop` | 1482 | 3.58 × 3.58 × 8.44 | Верх башни 3.2 × 3.2 м: кирпичный ярус с четырьмя циферблатами, открытый ярус арок, шатёр, шпиль с шаром и флюгером. Стрелки — 8 отдельных объектов, время 10:10. |

- **Пивоты.** Прилавок, купол, фонтан — центр основания на земле. Купол ставится на конёк или плоскую крышу (постамент может утонуть в кровле). Верх башни — центр нижнего пояса, ставится на ствол 3.2 × 3.2 м.
- **Колокол** висит: пивот — ось качания (вращать корень вокруг X). `LM_ChurchBell_Clapper` — пивот на шарнире под короной (0, 0, −0.24). Проверка «основание на z = 0» для колокола отключена.
- **Стрелки** `LM_ClockTowerTop_Hand_{Hour,Minute}_{S,E,N,W}` — пивот в центре своего циферблата; вращать вокруг мировой горизонтальной оси, перпендикулярной грани (S, N — ось Y; E, W — ось X). Циферблаты — `LM_ClockTowerTop_Emissive` (ночная подсветка).
- **Сокеты.** `LM_MarketStall_SOCKET_Interact` (0, −1.10, 1.0) — покупатель; `LM_MarketStall_SOCKET_Seller` (0, 0.95, 0) — продавец за прилавком; `LM_Fountain_SOCKET_JetTop` (0, 0, 3.22) — источник VFX струи.
- **Коллайдеры (совет).** Прилавок — box по прилавку; фонтан — mesh/8 box по бортику + capsule колонны; купол, колокол и верх башни обычно вне досягаемости — box по габариту.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1
python3 ArtSource/Props/LANDMARKS/OLD_TOWN/build_old_town.py -- --revision 1
```

Результат: `LM_*_v01.fbx`, `LM-OLD_TOWN_v01.blend`, `validation_LM_*_v01.json`, `Previews/v01/`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью.
