# LANDMARKS — ориентиры долинки и старого города (общие правила)

Стилизованные low-poly ориентиры для маленькой долины (казино, ночной клуб, боулинг, билборды, заправка) и старого города (рынок, колокол, купол, фонтан, часовая башня). 2 семейства, 14 ассетов, 312–1482 треугольника на ассет (бюджет 200–1500). Модели строятся скриптами Blender Python (`bpy` 5.0.1 из PyPI или Blender 5.x, фоновый режим). Отчёт — `PRODUCTION_REPORT.md`; таблицы треугольников и габаритов — в README семейств.

| Папка | Что внутри |
|---|---|
| `VALLEY/` | крышная вывеска «КАЗИНО» с короной и лампочками; неон клуба (полосы, звезда, коктейль); гигантские кегля и шар на крышу боулинга; билборды 6 × 3 и 3 × 1.5 м; бензоколонка |
| `OLD_TOWN/` | рыночный прилавок с полосатым навесом; церковный колокол с языком; луковичный купол; фонтан площади; верх часовой башни со стрелками |
| `_lib/` | `landmarks.py` — тонкая надстройка над `../STREET_KIT/_lib/streetkit.py` |

## Соглашения — как у STREET_KIT

Всё, что описано в `../STREET_KIT/README.md`, действует и здесь: Z вверх, метры, перед −Y; FBX `axis_forward=-Z`, `axis_up=Y`, `apply_unit_scale=True`; корневая пустышка с именем ассета в (0, 0, 0); пивот — центр основания на земле; плоское сглаживание; сетки замкнутые, нормали наружу (`validation_<Ассет>_v01.json`, `all_checks_passed`). Ревизии не перезаписываются: новая — `--revision N+1`, `--force` только для пересборки той же ревизии.

Отличия и дополнения:

- **Общая палитра.** Тот же материал `SK_Palette` и та же текстура `STREET_KIT/_lib/SK_Palette.png` (8 × 4 ячейки), UV0 в центре ячейки + вершинный цвет `Col`. Новых цветов нет; `landmarks.py` не перезаписывает палитру STREET_KIT, если она уже есть.
- **Светящиеся части — отдельный дочерний меш `<Ассет>_Emissive`**: неоновые трубки, лампочки казино, окошки и лайтбокс колонки, циферблаты часов. В Unity им ставится эмиссивный вариант палитры (тот же атлас в Emission, интенсивность по вкусу); остальное — обычный `SK_Palette`.
- **Постеры билбордов — материал `LM_Poster`**, UV 0..1 на всю лицевую грань (пропорция 2 : 1). Одна текстура постера на экземпляр; в .blend и превью — заглушка.
- **Навесные (неон)**: стена — плоскость y = 0, трубки на 0.10 м перед стеной, пивот — на стене у низа трансформатора.
- **Не на земле**: колокол (пивот на оси качания), проверка `base_on_ground_z0` для него отключена.
- **Подвижные части** — отдельные меши с пивотом на оси: язык колокола, пистолет колонки, стрелки часов (8 шт.).

## Импорт в Unity (рекомендация, не проверено)

Как в `../STREET_KIT/README.md`: Scale Factor 1, Convert Units, Import Normals = Import, общий URP Lit `SK_Palette` (Point, без сжатия). Дополнительно: материал `SK_Palette_Emissive` для `*_Emissive`, `LM_Poster` для `*_Poster`, водный материал для `LM_Fountain_Water`. Коллайдеры не входят в FBX — советы в README семейств.

## Сборка всего набора локально (из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11
python3 ArtSource/Props/LANDMARKS/VALLEY/build_valley.py -- --revision 1
python3 ArtSource/Props/LANDMARKS/OLD_TOWN/build_old_town.py -- --revision 1
```

Сборка с превью Cycles на CPU занимает несколько минут на семейство; `--no-render` — секунды; `--samples N` меняет качество превью. В облаке .blend, .fbx и .png не отправлялись: в репозитории только скрипты, README и JSON проверок.
