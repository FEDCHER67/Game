# SYRINGE-ASTRA-001 — source provenance

The four PNGs in `Source/TripoViews/` were newly generated for this project on 2026-09-29. They depict the same original stylized syringe from front, left, right, and back. They are not screenshots or textures extracted from an external 3D model.

The user approved design A with a refined, elegant nozzle. The high-level design cues came from:

- [Fab / Ndevisuals cartoon syringe](https://www.fab.com/listings/6922fae8-1cc0-45f0-844e-df417ca4dd2c): broad finger flange, thick chamber, large thumb pad.
- [Sketchfab / Alexander Troianovskyi medical syringe](https://sketchfab.com/3d-models/medical-syringe-22e711221a094a48a6ffe826d3fd6185): visible clear chamber and a separate plunger mechanism.
- [Wikimedia Commons / syringe parts](https://commons.wikimedia.org/wiki/File:Syringe-parts.jpg): basic barrel, stopper, plunger relationship.

No donor mesh, branding, markings, or downloaded reference imagery entered the four generated views. The existing heart, kidneys, lungs, and brain in this repository are the intended finish and color family for the later Blender work.

Tripo generated the base on 2026-09-29 from the four original PNG views: [syringe model page](https://studio.tripo3d.ai/ru/workspace/generate/pink-brain-model-with-smooth-lobed-surface-03c2acf3-9205-4400-85a2-7bc10b7e9739). Its untouched FBX export is `Working/Tripo/syringe_tripo_base.fbx`. The account-specific terms for reuse were not reviewed here; check them before external distribution.
