# VAN-TIER0-ASTRA-001 — фургон уровня 0

Статус: **v02 лично принята Федей** (04.10.2026, «братан это шедевр») вместе с ездой и дверями в Unity. v01 — промежуточная ревизия, сохранена.

## Дизайн

- Силуэт и пропорции — по фото старого белого фургона класса VW T4 от Феди (низкая крыша, короткая наклонная морда, колёса по углам). Бренд, логотип и номера не переносились; фото в репозиторий не добавлялось.
- Детализация и стиль — по эталону Феди `Source/Concept/DetailReference_OwnerApproved.png` (гранёный low-poly с фасками, матовые цвета, круглые фары в тёмной рамке, решётка с полосами).
- Утверждённые ракурсы REV07 (сгенерированы в «Федя чат»): `Source/TripoViews/Rev01/01_front, 02_left, 03_right, 04_back.png` (1448×1086). Tripo не использовался, кредиты не тратились: модель построена процедурно в Blender по этим ракурсам.
- Сдвижная дверь — правый борт (решение Феди), с ручкой и полосой-направляющей; левый грузовой борт глухой. Сзади две распашные двери с окнами.

## Файлы

| Файл | Что это |

| `build_van.py` | Источник модели. `blender -b --factory-startup --python build_van.py -- --revision N`. Никогда не перезаписывает существующую ревизию. |

| `VAN-TIER0-ASTRA-001_v01.blend` / `.fbx` | Первая ревизия: закрытая кабина, открывались 3 двери. Собрана предыдущей версией скрипта. |

| `Previews/v01`, `Previews/v02` | Рендеры Cycles; в v02 также открытые двери и вид с места водителя. |

## v02 — технические данные

- Blender: Z вверх, −Y вперёд, метры; левый борт (водитель) = +X, правый (сдвижная дверь) = −X.
- Габариты 4.78 × 1.88 м (2.14 с зеркалами), высота 2.08 м; колёса R 0.37 м, база 3.16 м.
- 2514 треугольников: корпус 1172, двери 148/148/56/56/70, руль 208, колёса по 164. 12 матовых материалов `VAN_*`, без текстур; стекло полупрозрачное.
- Кабина и грузовой отсек — одна полая область (стенки 5 см, пол на высоте 0.55 м, арки колёс внутри). Проёмы лобового и боковых стёкол настоящие, стёкла двусторонние.
- Отдельные объекты с пивотами: передние двери — петля у передней кромки (−70°/+70° по Z), сдвижная — передний нижний угол (отход −0.07 X, затем +1.02 Y), задние — внешние кромки (−100°/+100°), руль — центр обода, колёса — центр (ось X), `SOCKET_DriverEye` — глаза водителя.
- Открытые рёбра в validation — только стёкла (двусторонние квады), это ожидаемо.
