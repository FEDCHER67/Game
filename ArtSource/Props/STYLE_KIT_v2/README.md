# STYLE_KIT_v2 — модели вида карты по STYLE_BIBLE_v2

Набор моделей, собранных строго по `docs/art/STYLE_BIBLE_v2.md`: деревья, кусты, трава, дома старого города, средняя «сталинка», секция панельки и набор площади (фонтан с памятником, лавка, фонарь, вазон). Всё строится детерминированными скриптами Blender `bpy` в фоновом режиме: одинаковый запуск даёт байт-в-байт ту же геометрию (хэш геометрии пишется в JSON проверок). Это эталон «сделано руками» для пробного кадра (библия, раздел 12) и для раскатки — `ProceduralBuilding` и `TerrainBaker` сверяются с ним.

`STYLE_KIT_v1` и `STYLE_BIBLE_v1.md` не тронуты.

## Сборка (из корня репозитория)

```
B="C:/Program Files/Blender Foundation/Blender 5.2/blender.exe"
for f in TREES/build_trees BUSHES/build_bushes GRASS/build_grass HOUSES/build_houses SQUARE/build_square SHOWCASE/build_showcase; do
  "$B" -b --factory-startup --python ArtSource/Props/STYLE_KIT_v2/$f.py -- --revision 1
done
"$B" -b --factory-startup --python ArtSource/Props/STYLE_KIT_v2/_lib/build_palette_sheet.py
```

- `SHOWCASE` собирать последним: он берёт ассеты из `.blend` семейств.
- Ключи: `--revision N` (новая ревизия — новые файлы `_v0N`), `--force` (пересобрать ту же ревизию), `--no-render` (без превью, секунды), `--samples N`, `--cpu`, `--out <папка>` (собрать в другую папку), `--only <часть имени превью>`.
- Существующая ревизия без `--force` не перезаписывается (правило проекта). Семейство целиком — 10–70 секунд на GPU (Cycles, OptiX).

## Соглашения

- Blender: Z вверх, метры, перед −Y. FBX: `axis_forward=-Z`, `axis_up=Y`, `apply_unit_scale=True` — как у `MAP_PROPS`, `STREET_KIT`, `LANDMARKS`.
- Один корневой меш на ассет, пивот — центр основания на земле (0, 0, 0). Дочерние меши: `<Ассет>_Water` (вода фонтана) и `<Ассет>_Emissive` (стекло фонаря, материал `Look_Palette_v2_Emissive`).
- **Один материал** `Look_Palette_v2` с атласом `_lib/Look_Palette_v2.png` (256 × 256, клетки 16 px). Атлас генерируется из JSON приложения А библии при каждой сборке; строки: ядро (22), `.light`, `.dark`, акценты, градиенты (клетки 16 × 96 px). UV0 каждой грани лежит внутри клетки её образца: у плоских образцов — в центре, у градиентов V = доля высоты формы. Альфа атласа = smoothness URP: 0.05 везде, стекло 0.35, вода 0.55, эмиссия 0.20.
- Градиенты (уровень 2 библии, только органика): кроны — верх `.light`, низ `.dark` (смешение градиента всей кроны и каждой доли), кусты, трава (у основания цвет зоны, к кончикам `.light`), вода. Свои цвета скрипты не придумывают — только образцы библии и их ступени.
- Нормали записаны как custom split normals: плоские (дома, ель), гладкие (доли крон), weighted (фаски пропсов: большие грани плоские, фаски скруглены), «вверх» (трава освещается как земля). Вершинный цвет не используется (URP Lit его игнорирует).
- Сетки замкнутые: каждое ребро делят ровно две грани, обход согласован, нормали наружу; случайного смещения вершин нет нигде, асимметрия задаётся шаблоном.

## Проверки (`validation_v01.json`)

На каждый ассет: треугольники и бюджет из раздела 4 библии, габариты, `closed_meshes`, `normals_outward`, `uv0_on_palette_cells` (каждая UV-точка в клетке своего образца), `swatches_from_bible`, `one_palette_material`, `pivot_at_origin`, `base_on_ground_min_z_0`, `min_member_ge_0.06_m`, `facet_rule_organic_ge_1_8` (правило фасеток 3.5), `deterministic_rebuild_identical` (ассет строится дважды, хэши совпадают), `geometry_sha1`.
Дополнительно у деревьев — высота, ширина кроны и низ кроны по таблице 5.1 и JSON, ветви ≥ 0.10 м; у домов — правила R1–R3 и пары стена → крыша (2.6); у пропсов — ≤ 3 образцов. Повторная сборка в отдельном запуске Blender дала те же `geometry_sha1` у всех 28 ассетов.

## Импорт в Unity (рекомендация, в проекте не подключено)

- FBX: Scale Factor 1, Convert Units, Normals = **Import**, Tangents = None, без коллайдеров (их строит `MapArtSetup`).
- Текстура `Look_Palette_v2.png`: sRGB, Alpha Source = Input Texture Alpha, Alpha Is Transparency выкл., **Filter Point, без mipmaps**, без сжатия, Wrap Clamp.
- Материал URP Lit `Look_Palette_v2`: Base Map = атлас, Smoothness Source = Albedo Alpha, Smoothness = 1, Metallic 0. Для `*_Emissive` — тот же атлас в Emission (×1.5 днём, ×3 ночью). Воду фонтана можно заменить анимированным материалом.
- Высоту деревьев задаёт план через `TerrainBaker` (библия 5.3); модель фиксирует пропорции. Масштаб — только равномерный (природа 0.92–1.08).
- Подключение к реестру (`tree/linden` → `TR_Round`, `tree/fruit` → яблоня и т. д., 5.7) и пробная сцена `Map_Look_v13_trial.unity` — следующий шаг, этой задачей не делались.

## Как здесь убран «нейрослоп» (по причинам из аудита)

| Причина | Что сделано в ките |
|---|---|
| Фото-грязь на каждой стене, крыше, земле | Нет ни одной текстуры, кроме атласа палитры: плоский цвет образца. Единственный рисунок — линии черепицы у терракотовой крыши и швы панелей (плоские полосы `.dark`, как PT_RoofTile / PT_PanelSeams из 3.3). |
| 77 мутных оттенков, серые тримы, чёрные окна | Цвета домов — по рецепту района и парам стена → крыша: сливочный + терракота, коралл + шифер, охра + плоская серая крыша, панель + кобальтовые балконы. Тримы `chalk` светлее стены (R2 проверяется), окна `glass` с 15–20 % `glass.light`, никаких «почти чёрных дыр». |
| Кроны из мятых икосфер, деревья выше домов | Каждая крона — шаблон из 3–5 гладких долей (subdiv 2, без jitter) или одна выточенная колонна (тополь) или 8-гранные ярусы (ель); светлый верх, тёмный низ; толстые стволы с прикорневым расширением и видимыми ветвями; правило фасеток. Высоты A/B — из таблицы 5.1 (липа 8/6 м при карнизе трёхэтажки 10 м). |
| Нет края, тонкие детали мерцают | Пилястры 0.40, пояса 0.22, наличники 0.12, подоконники 0.10 × 0.12, кресты в окнах, белые фасции и софиты под свесом 0.5 м, крышки парапетов 0.40; окна — настоящие ниши 0.15 м. Минимальная толщина детали 0.06 м проверяется. |
| Случайность вместо решения | Никакого шума: асимметрия одна и задана шаблоном (крона смещена на 5–8 %, наклон берёзы и тополя, излом ствола сосны, дверь не по центру, труба у фронтона). Пропсы — ≤ 3 образцов, двухсегментные фаски с weighted-нормалями, как «пухлость» Tripo. |

- LOD1 (5.2.7), яблоня `TR_Apple` и пальма `TR_Palm` (в библии есть, в задаче — 5 пород × 2), кустарниковые варианты `BU_Flower` других цветов, `GR_DuneGrass`, цветы `mustard` / `cobalt` / `lilac` (в `build_grass.py` это одна строка в списке цветов).
