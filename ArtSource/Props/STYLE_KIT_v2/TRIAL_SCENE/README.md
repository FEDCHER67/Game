# TRIAL_SCENE — как собирается `Map_Look_v13_trial.unity` (библия v2, раздел 12, правка v2b)

Пробная сцена строится целиком из плана `ArtSource/References/Map/Look/look_v12_flat.json` (только чтение) и моделей `STYLE_KIT_v2` v02. Код проекта (`*.cs`) не используется и не правится: раскладка считается здесь на Python, а сцену собирает C#-сниппет через Unity MCP (`execute_code`).

| Файл | Что делает |
|---|---|
| `make_layout.py` | Земля и расстановка по плану: сетка рельефа 5 м (луг; лес — газон), море-плоскость, пляж, озеро, канал с бетонными берегами; дороги двух образцов (`road` в старом городе и элитке, `asphalt` у панелек, в промзоне и на магистралях), перекрёстки, разметка, зебры; тротуары с бордюром `chalk.dark`; площадь — приподнятая плитка 1.5 м с бордюром; сады и палисадники — газон. Расстановка: 76 домов `HS_P_<id>_v02` по `plan_buildings_v02.json`, ландмарки (фонтан кита, рыночные лотки, башня с часами = `SQ_ClockShaft` + верх из `LANDMARKS`, билборды, неон), фонари (`SQ_LampPost` в старом городе), лавки, урны, машины; деревья — породы 5.4, высоты 5.3, правила v2b (кольцо лип B через 12 м по площади, одиночки → тройки или убрать, коридор вида 14 м перед фасадами, кусты по опушке леса); изгороди по палисадникам и вдоль площади; трава у цоколей и пучками на лугу рядом с камерами; ограда элитки; 6 NPC (готовые префабы `SausageBuddy_A/B`). Пишет `out/ground_v2b.txt`, `out/place_v2b.txt`, `out/layout_v2b.json` (5 с) |
| `plot_layout.py` | Проверочный вид сверху: `python plot_layout.py x0 x1 y0 y1 px_per_m out.png` |
| `build_v13_trial_scene.cs.txt` | Сборка сцены в Unity (вставить в `execute_code`, редактор не в Play): меши земли → `Assets/OnlyVolunteers/Art/StyleKit_v2/Meshes/Map_Look_v13_trial_Ground_*.asset`, экземпляры моделей и префабов, NPC в позе idle (аниматор считается один раз, префабы не меняются), свет библии 9.1 (туман 150–1200 м), объём `Look_PostFX_v2`, четыре камеры |
| `render_v13_trial.cs.txt` | Рендер всех `Cam_*` 1920 × 1080 через копию пайплайна `PC_RPAsset_StyleTrial_v2` (MSAA 4×, тени 180 м / 4096, SSAO), затем возвращает проектный пайплайн |
| `metrics.py` | Доли полос L* (B1+B2 = L* ≥ 78), «зелёных» и «тёплых» пикселей и средний L* кадра — определения подогнаны под цифры разбора от 07.10 |
| `sheet_v2b.py` | Лист «было / стало» `ArtSource/References/Art/StyleTrial_v2b_BeforeAfter.png` с подписями и цифрами |
| `cal/` | Как найдены позы камер `square_a` и `play_npc_clock`: рендер `Map_Look_v12` с пробной позой → автоматическое сопоставление фрагментов с кадром от 05.10 (`match.py`) → луч в сцену даёт мировые точки → поза и FOV по наименьшим квадратам (`pnp.py`, `solve_ref.py`); медиана ошибки 1 px |
| `heights_full_4m.txt` | Высоты рельефа `Terrain_v12.asset` с шагом 4 м (снято из Unity) |
| `registry_map.json` | Ключи `MapLookRegistry` → пути префабов (снято из `MapLookRegistry.asset`) |

`out/` — сгенерированное (≈ 13 МБ), пересобирается за секунды; в репозиторий класть не обязательно.

Позы камер (Unity, метры): `Cam_SquareA` (600.037, 13.975, 512.065), Euler (11.127, 53.772, 0), FOV 55.13; `Cam_PlayNpcClock` (645.94, 3.08, 538.80), Euler (17.54, 224.80, 0), FOV 55.08; `Cam_Facade_1p6m` из (526.38, 1.6, 499.47) на (536.61, 4.6, 510.44), FOV 55; `Cam_Wide` из (545, 92, 415) на (662, 0, 560), FOV 50.
