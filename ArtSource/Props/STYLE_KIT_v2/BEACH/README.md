# BEACH — пляжный набор STYLE_KIT_v2

17 ассетов по `STYLE_BIBLE_v2b` и схеме Феди `REF_FEDYA_MASTER_v02_city_beach.png`. **Актуальная v03**: редактируемый `SK2-BEACH-001_v03.blend`, отдельные `<имя>_v03.fbx`, `validation_v03.json`, `export_audit_v03.json`, `style_audit_v03.json`, пять новых превью в `Previews/v03/`. v01/v02 сохранены целиком: модели, FBX, проверки и превью. В v03 кнехт уменьшен до 0,70 м, перекрашен в `grey` / `grey.dark`; на пирсе шесть кнехтов. Остальные 16 ассетов совпадают с v02 по хэшам геометрии. Перед — −Y, Z вверх, метры; пивоты FBX на земле в (0, 0, 0). В `.blend` модели разложены рядами для просмотра.

Один материал `Look_Palette_v2`, существующий атлас `../_lib/Look_Palette_v2.png`; в `.blend` атлас упакован. На пропсе максимум три семейства образцов. Красные и синие полосы — `red` / `cobalt` + `chalk`, оранжевые — разрешённый `terracotta` (8.2). Фаски у мебели и вывесок двухсегментные, нормали weighted; структурные брусья ≥ 10 см. Пальмы — веер из 8–10 объёмных гладких листьев толщиной 7–8 см, без мелких листочков; A ≈ 7 м, B = 5,5 м, только у пляжа/пирса. Камни — гладкий цельный объём. Фото, шум, jitter, текст, люди и анимации отсутствуют.

Пирс: модуль настила ровно **2 × 2 м**, шаг вдоль Y 2 м, верх Z = 0,28 м. Т-конец: голова 6 × 2 м, стебель 2 × 1 м в сторону +Y; следующий модуль стыкуется центром Y = +3 м от центра головы. Кнехт — отдельный пропс: высота 0,70 м, ширина шляпки до 0,52 м, корпус `grey`, шляпка `grey.dark`; основание на настиле. В превью четыре кнехта на длинной части и два на Т-конце, их основания и шляпки внутри края настила. Дополнительные сваи не добавлены; существующие низкие подбалки деревянные. В обзорном кадре слева киоск, справа душ/туалет, у каждого зонта два шезлонга и столик; круглые кусты в вазонах — только декорация превью из готового BUSHES, не новые FBX.

Сборка из корня репозитория:

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.2/blender.exe' -b --factory-startup --python-exit-code 1 --python ArtSource/Props/STYLE_KIT_v2/BEACH/build_beach.py -- --revision 4
```

Ключи: `--revision N`, `--force` как в остальных семействах, `--no-render`, `--samples N`, `--cpu`, `--only <часть имени>`. **Для правок моделей всегда новая ревизия; v01/v02 не перезаписывать.** `--check-only` проверяет без экспорта. `--preview-existing` добавляет только отсутствующие кадры существующей ревизии после сравнения всех хэшей; FBX, `.blend`, JSON и готовые PNG не переписывает. `--out` разрешён только внутри BEACH. `beach_support.py` отключает запись общих атласа, карт и сводки кита; библиотека используется импортом, байткод не создаётся.

Проверки: замкнутость, обход/нормали, UV в ячейках библии, один материал, пивот/земля, толщина, бюджеты, отсутствие jitter и анимации, два одинаковых построения каждого ассета; дополнительно размеры модулей и пропорции пальм. `verify_beach.py -- --revision 3` проверил повторный импорт всех FBX и состав `.blend` → `export_audit_v03.json`. `verify_style_v03.py` проверил CIELAB-полосы всех 17 ассетов, контраст пар образцов ΔE76 ≥ 9 и долю B6 в пяти новых PNG → `style_audit_v03.json`. Аудиты не перезаписывают готовые отчёты.

Превью v03: `01_BE_Pier_Post.png` — изменённый кнехт, `02_lineup.png` — полный набор, `03_beach_reference_top.png` — схема пляжа, `04_beach_eye_level.png` — уровень глаз, `05_style_neighbours.png` — рядом с SQUARE/TREES при том же свете, включая кнехт возле шезлонга. Индивидуальные рендеры остальных неизменённых ассетов остаются в `Previews/v02/`. Свет — общий Cycles-стенд кита, без тонмаппинга. Все пять новых кадров просмотрены; заключение — `visual_review_v03.md`. Окончательное художественное принятие остаётся за владельцами Work. В Unity не импортировано; LOD1 не входит в эту поставку.
