# VEHICLES_KIT — отчёт о производстве

Статус: **черновик облака v01, Федей не просмотрен.** В Unity не импортировано, в игре не проверено.

## Что сделано

Набор припаркованного транспорта для карты: постсоветский город, слегка мультяшно, в одном стиле с STREET_KIT и фургоном. 4 семейства, 12 ассетов, у всех проверки пройдены (`validation_*_v01.json`, `all_checks_passed: true`), бюджет 600–1500 треугольников соблюдён.

| Семейство | Ассеты | Треуг. |
|---|---|---|
| CARS | седан-«классика» ×4 цвета (голубой, вишнёвый, бежевый, зелёный), хэтчбек-«зубило», полицейский седан с мигалкой | 952–1328 |
| VANS | микроавтобус-«буханка», скорая помощь с высокой будкой | 1168–1268 |
| HEAVY | эвакуатор с краном, городской автобус ~10.5 м, маленький трактор | 828–1472 |
| SCOOTER | мотороллер на подножке | 652 |

- Всё собрано процедурно скриптами `build_*.py`; общие для машин функции (колёса, ниши арок, кузов с арками, стёкла, фары, мигалки, кресты) — в `_lib/vehiclekit.py`, который опирается на `STREET_KIT/_lib/streetkit.py`. Оси, пивоты, экспорт FBX, проверки и превью — ровно как в STREET_KIT. Общие правила — `README.md`.
- Палитра та же — один материал `SK_Palette`, новых цветов нет, так что машины батчатся с уличным набором.
- Каждая машина — один меш под корневой пустышкой, без салона (стёкла тёмные), без подвижных частей, без логотипов, надписей и номеров.
- Нос в −Y, водитель слева (+X); двери автобуса, «буханки» и скорой — с правого борта (−X), к тротуару. Автобус по высоте пола и дверей подходит к павильону остановки STREET_KIT.
- Разбитая и сгоревшая «классика» уже есть в `STREET_KIT/WRECKS`; новый седан с ней по пропорциям совпадает (длина ~4.1 м), но собран заново без повреждений.

## Как делали

Ведущий облачной сессии написал библиотеку и все четыре семейства сам (без субагентов — так стиль и общие функции получились единообразными). После каждой сборки смотрел превью Cycles, правил посадку колёс, бюджет (эвакуатор сначала вышел на 1508 треугольников — убрал лишние планки решётки) и отдельно рендерил правые борта автобуса и скорой, чтобы проверить двери, которых не видно на стандартном превью.

## Что не отправлено и что открыто

- **.blend, .fbx и .png не в репозитории** (LFS из облака заблокирован). Собрать локально командами из README семейств; результат детерминирован. После сборки вернуть `STREET_KIT/_lib` командой `git checkout -- ArtSource/Props/STREET_KIT/_lib` (палитра перезаписывается теми же цветами).
- Нужен просмотр Феди: силуэты, пропорции, цвета. Превью — в `Previews/v01/` после локальной сборки.
- Импорт в Unity, общий URP-материал, коллайдеры и префабы не делались; советы по коллайдерам — в README семейств.
- Табло маршрута автобуса — пустая белая табличка; если нужен номер маршрута, можно перевести её на материал `SK_Signage` (атлас вывесок STREET_KIT).
- Колёса слиты с кузовом: если машины когда-нибудь поедут, колёса придётся выделить в отдельные объекты.
