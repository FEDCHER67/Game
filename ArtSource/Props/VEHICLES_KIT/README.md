# VEHICLES_KIT — припаркованный транспорт (общие правила)

Стилизованный low-poly набор статичного транспорта для карты: 4 семейства, 12 ассетов, 652–1472 треугольника на ассет. Модели строятся скриптами Blender Python (`bpy` 5.0.1 из PyPI или Blender 5.x, фоновый режим) на библиотеке `STREET_KIT/_lib/streetkit.py` — оси, пивоты, экспорт, проверки, превью и палитра те же, что в `../STREET_KIT/README.md`. Обзор и статус — `PRODUCTION_REPORT.md`; таблицы треугольников и команды сборки — в README каждого семейства.

| Папка | Что внутри |
|---|---|
| `CARS/` | седан-«классика» в 4 цветах (голубой, вишнёвый, бежевый, зелёный), хэтчбек-«зубило», полицейский седан с мигалкой |
| `VANS/` | микроавтобус-«буханка», машина скорой помощи (фургон с высоким кузовом) |
| `HEAVY/` | эвакуатор с краном на капотном грузовике, городской автобус (под павильон остановки), маленький трактор |
| `SCOOTER/` | мотороллер на центральной подножке |
| `_lib/` | `vehiclekit.py` — надстройка над `streetkit.py`: колёса, ниши арок, кузов с арками, стёкла, фары, мигалки, кресты |

## Соглашения

- Всё как в STREET_KIT: Blender Z вверх, метры; FBX `axis_forward=-Z`, `axis_up=Y`, `apply_unit_scale=True`, плоское (FACE) сглаживание, без анимации.
- Нос машины смотрит в −Y. Значит, сторона водителя (левая) — +X, правая (тротуарная) — −X: пассажирские двери автобуса, «буханки» и скорой — на −X.
- Каждый ассет — корневая пустышка `VK_<Ассет>` в (0, 0, 0) и **один** дочерний меш `VK_<Ассет>_Mesh`. Пивот — центр основания на земле; плоские низы шин стоят на z = 0.
- Статичные пропы: без салонов (стёкла тёмные, непрозрачные), без подвижных частей и сокетов. Номерные знаки — пустые белые таблички, логотипов и надписей нет.
- Сетки замкнутые, нормали наружу, без вырожденных граней — это проверяет `validation_<Ассет>_vNN.json` (`all_checks_passed`). Бюджет набора — **600–1500 треугольников** на ассет (записан в каждый JSON как `triangle_budget`).
- Ревизии не перезаписываются: новая версия — `--revision N+1`; `--force` только для пересборки той же ревизии в черновике.

## Палитра и материалы

- Тот же общий материал **`SK_Palette`** и текстура `../STREET_KIT/_lib/SK_Palette.png` (8 × 4 ячейки по 16 px); новых цветов не добавлено, поэтому машины батчатся вместе с уличным набором. UV0 каждой грани — в центре ячейки её цвета, тот же цвет — в вершинном цвете `Col`.
- Сборка любого семейства заново записывает `SK_Palette.png` и `signage_atlas_layout.json` в `STREET_KIT/_lib/` (цвета те же). Если git покажет их изменёнными — `git checkout -- ArtSource/Props/STREET_KIT/_lib`.
- Цвета кузовов: седаны `car_blue`, `red`, `cream`, `green`; хэтчбек `purple` («баклажан»); полиция `white` + `sign_blue`; «буханка» `green`; скорая `white` + `sign_red`; эвакуатор `orange` + `yellow`; автобус `cream` + `red` + `white`; трактор `red` + `white`; мотороллер `teal`.
- Цвет седана зашит в UV и вершинные цвета, поэтому 4 цвета — 4 отдельных FBX с одинаковой геометрией. Если понадобится больше цветов, дешевле добавить вариант в `COLOURS` в `CARS/build_cars.py`, чем перекрашивать в Unity.

## Импорт в Unity (рекомендация, не проверено)

- Как у STREET_KIT: один URP Lit-материал `SK_Palette` (Point-фильтр, без сжатия), Scale Factor 1, Convert Units включено, Import Normals = Import, материалы — переназначить на общий.
- Коллайдеры не входят в FBX: советы по каждому семейству — в его README. Для всех машин хватает одного-двух box.
- Машины статичные; если когда-нибудь понадобится их двигать, колёса надо будет выделить в отдельные меши (сейчас всё слито в один).

## Сборка всего набора локально

```
pip install bpy==5.0.1          # Python 3.11
for s in CARS/build_cars VANS/build_vans HEAVY/build_heavy SCOOTER/build_scooter; do
  python3 ArtSource/Props/VEHICLES_KIT/$s.py -- --revision 1 || break
done
git checkout -- ArtSource/Props/STREET_KIT/_lib     # палитра пересобрана теми же цветами
```

Полная сборка с превью Cycles на CPU занимает около 5 минут; `--no-render` — секунды. В облаке .blend, .fbx и .png не отправлялись (загрузка LFS заблокирована): в репозитории только скрипты, README и JSON.
