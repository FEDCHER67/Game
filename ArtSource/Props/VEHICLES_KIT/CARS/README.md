| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `VK_Car_Sedan_Blue` | 1260 | 1.72 × 4.08 × 1.42 | Седан 70-х в пропорциях «классики» (без логотипов): четыре круглые фары в чёрной решётке, хромированные бамперы с клыками, хромированные колпаки, четыре двери с ручками, зеркало со стороны водителя, дворники. Голубой. |
| `VK_Car_Sedan_Red` | 1260 | 1.72 × 4.08 × 1.42 | То же, вишнёвый. |
| `VK_Car_Sedan_Beige` | 1260 | 1.72 × 4.08 × 1.42 | То же, бежевый. |
| `VK_Car_Sedan_Green` | 1260 | 1.72 × 4.08 × 1.42 | То же, зелёный. |
| `VK_Car_Hatchback` | 952 | 1.67 × 4.22 × 1.40 | Трёхдверный хэтчбек 80-х, «зубило»: клиновидный низкий нос, крутая пятая дверь с козырьком на крыше, прямоугольные фары, чёрные пластиковые бамперы и молдинги, штампованные диски. Цвет «баклажан». |
| `VK_Car_Police` | 1328 | 1.72 × 4.08 × 1.57 | Полицейский вариант седана: белый, синяя полоса по бортам и по капоту, балка мигалки на крыше (красный / белый / синий). Без надписей. |

- Седаны и полиция построены одной функцией `sedan()`, хэтчбек — `hatchback()`; цвета — список `COLOURS` в скрипте. Нос в −Y, сторона водителя +X.
- Ширина по габариту включает зеркало и колпаки; кузов 1.60 × 3.86 м (с бамперами 4.08 м), колёса R 0.30 м, колея 1.42 м.
- Коллайдер: один box по кузову (≈ 1.6 × 4.0 × 0.9 от z = 0.25) плюс box по кабине (≈ 1.4 × 1.9 × 0.55); проще — один box 1.6 × 4.0 × 1.4.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/VEHICLES_KIT/CARS/build_cars.py -- --revision 1
```

Результат: `VK_*_v01.fbx`, `VK-CARS_v01.blend`, `validation_VK_*_v01.json`, `Previews/v01/`, а также общая палитра `../../STREET_KIT/_lib/SK_Palette.png`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.
