- Нос в −Y, сторона водителя +X, пассажирские двери на −X. Ширина по габариту включает зеркала.
- Коллайдер «буханки»: box 1.94 × 4.36 × 1.5 от z = 0.55 (под кузовом можно оставить пусто — колёса и мосты мелкие). Скорая: box будки и кабины 2.04 × 4.6 × 2.05 от z = 0.45 и box капота 2.0 × 0.95 × 0.75.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/VEHICLES_KIT/VANS/build_vans.py -- --revision 1
```

Результат: `VK_*_v01.fbx`, `VK-VANS_v01.blend`, `validation_VK_*_v01.json`, `Previews/v01/`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.
