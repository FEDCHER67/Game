# VK-SCOOTER — мотороллер

Статус: **черновик облака v01, Федей не просмотрен.** В Unity не импортировано.

| Ассет | Треуг. | Габарит X × Y × Z, м | Что это |
|---|---|---|---|
| `VK_Scooter` | 652 | 0.74 × 1.84 × 1.37 | Советский мотороллер 60-х на центральной подножке, мятный: скруглённый задний капот с хромированными молдингами, маленькие колёса, щиток для ног, переднее крыло, фара в рулевой головке, чёрное сиденье с хромированным багажником, глушитель справа (−X), зеркало слева. |

- Нос в −Y. Стоит ровно, без наклона: опора — оба колеса и подножка на z = 0.
- Коллайдер: один box 0.5 × 1.8 × 1.1 (или капсула вдоль Y); руль можно не учитывать.

## Сборка (локально, из корня репозитория)

```
pip install bpy==5.0.1          # Python 3.11; либо: blender -b --factory-startup --python <скрипт> -- ...
python3 ArtSource/Props/VEHICLES_KIT/SCOOTER/build_scooter.py -- --revision 1
```

Результат: `VK_Scooter_v01.fbx`, `VK-SCOOTER_v01.blend`, `validation_VK_Scooter_v01.json`, `Previews/v01/`. Существующую ревизию скрипт не перезаписывает без `--force`; `--no-render` пропускает превью. **.blend, .fbx и .png в облаке не отправлялись** (LFS заблокирован) — соберите локально.
