# WATER-TOWER-ASTRA-001 — водонапорная башня деревни

Статус: **v01 выбрана Федей** (04.10.2026, из трёх вариантов: «справа самая пиздатая»). В Unity пока не импортирована — понадобится при сборке деревни по плану карты.

- Ориентир деревни из спецификации карты (`docs/CITY_MAP_REFERENCE_SPEC.md`, §4.2, §13.2): постсоветская башня Рожновского — бак с коническим низом на высокой опоре, кольцевая площадка с перилами, лестница до крыши, ржавчина и облезлая краска.
- Высота 21,66 м, бак Ø 3,4 м, 1446 треугольников (бюджет ≤ 1500), 5 материалов с префиксом `WT_`, пивот в центре основания на земле. Габариты и проверка сетки — `validation_v01.json`.
- Собрано процедурно `build_water_tower.py` (Blender 5.2, фоновый режим). Пересборка: `blender -b --factory-startup --python build_water_tower.py -- --revision N` (существующую ревизию не перезаписывает без `--force`). FBX: axis_forward −Z, axis_up Y, apply_unit_scale.
- Происхождение: выполнено Claude Fable 5.1 в соревновании моделей Work Феди (наряду с вариантами GPT-6 Astra и Opus 5.5); в репозитории пересобрано из того же скрипта под именем ассета `WATER-TOWER-ASTRA-001`.
