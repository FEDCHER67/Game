# MW86_MonumentTramduro - sources

Original procedural low-poly model made by agent M2 (Claude, Opus 5.5) on 2026-10-22 for VOLUNTEERS ONLY,
built headless in Blender 5.2 by `../_common/build_static_m2_v01.py` (type builder in `../_common/props_*.py`,
shared geometry library `../_common/m2lib.py`).

- Third-party assets: none (no downloaded geometry or textures).
- Colours: own flat palette atlas `MW86_StaticPalette_v01` (Albedo / MetallicSmoothness / Emission, 256 px),
  generated by the same script; shared by every M2 static prop.
- Licence: project-owned original work.

Data kinds replaced: monument_tramduro; W85 placeholder box size [4.8, 4.8, 12.0].

## v02 (2026-10-22) - TRAMDURO in gold with a crown (replaces the generic leader in the same FBX)

Built headless in Blender 5.2 by `build_monument_tramduro_v02.py` (this folder; uses `../_common/m2lib.py` unchanged).
Saved as `MW86_MonumentTramduro_v02.blend` (statue only, no rig); v01 .blend kept.

- Figure: Vadim's project character TRAMDURO (`ArtSource/Characters/SAUSAGE_BUDDY_01/Types/TRAMDURO/SAUSAGE_BUDDY_TRAMDURO_v01.blend`,
  commit 976100c7), project-owned. Posed as a monument (right arm raised in a wave, left fist on the hip, chest out, chin up),
  pose baked, body + suit voxel-cast into one surface, small features (eyes, nose, hands, tie, lapels, buttons, pupils,
  brows, mouth) kept as separate decimated pieces; hidden faces removed by ray visibility. Flag pin and eye highlights dropped.
- Crown and podium: original procedural geometry (podium = v01 code). Colours: the shared `MW86_StaticPalette_v01` atlas
  (gold, gold_dark, red, blue, granite swatches). No downloaded assets, no text or logos.
