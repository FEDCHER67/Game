# MAP_PROPS / TEXTURES — процедурные тайлящиеся текстуры

Стилизованные (мультяшные, низкоконтрастные) бесшовные текстуры для земли, воды и растительности.
Сочетаются с плоскими цветами пропов (`_lib/mapprops.py`, палитра `MP_*`). Только numpy + Pillow, детерминированно:
один и тот же `--seed` даёт побайтно одинаковые PNG.

## Запуск (из корня репозитория)

```
pip install numpy pillow
python3 ArtSource/Props/MAP_PROPS/TEXTURES/gen_textures.py
```

Параметры: `--size 1024` (по умолчанию), `--seed 1`, `--only Sand,Grass`, `--out DIR` (родительская папка,
по умолчанию `TEXTURES/Out`), `--revision 1` (→ папка `v01`), `--force` (перезаписать существующую ревизию;
без него существующая папка ревизии не трогается). Полный прогон 1024² — около 80 с.

## Выход (`TEXTURES/Out/v01/`)

- `TX_<Name>_Albedo_v01.png` — 1024×1024 RGB, sRGB.
- `TX_<Name>_Normal_v01.png` — карта нормалей OpenGL/Unity (+Y вверх), из поля высот генератора, мягкая.
- `Previews/<Name>_preview.png` — 512 px, текстура 2×2 в половинном размере (видно швы).
- `Previews/contact_sheet.png` — все текстуры: сверху альбедо 2×2, снизу альбедо, освещённое нормалью.
- `textures_v01.json` — имя, файлы, размер, seed, `metres_per_tile`, средний RGB, проверка шва
  (разница колонок 0/N-1 и строк 0/N-1 против обычной разницы соседних пикселей) и `tileable_ok`.

**PNG из облака не отправлялись** (Git LFS в облаке заблокирован; в ветке только `textures_v01.json`) — генерируйте локально. Если PNG понадобятся в репозитории, они уйдут в LFS по правилу `*.png` из `.gitattributes`.

## Текстуры

| Имя | Что это | м на тайл |
|---|---|---|
| SeaWater | бирюзово-синее море, мягкая светлая сетка «каустики», редкие полосы пены; база для водного шейдера | 8 |
| Sand | тёплый пляжный песок, мягкая ветровая рябь, светлые/тёмные песчинки | 4 |
| Ground | голая земля, пятна подсохшей корки, кучки мелких камешков | 3 |
| Dirt | тёмная грунтовка: две колеи вдоль V, тёмные мокрые пятна-лужицы | 4 |
| Grass | газон: мягкие кочки с подсветкой сверху, вариации тона, редкие светлые травинки | 3 |
| Asphalt | серый изношенный асфальт: щебень, трещины, 2 заплатки | 4 |
| Concrete | советский панельный бетон: пятна, подтёки, поры, слабые следы опалубки (6 досок на тайл) | 3 |
| Bark | кора: вертикальные трещины и вытянутые пластины | 1 (по окружности ствола — подобрать U) |
| BirchBark | берёза: белая кора с горизонтальными чечевичками и чёрными отметинами | 1 |
| Leaves | крона/листва: перекрывающиеся стилизованные листья (без альфы) | 1.5 |

Тайлинг в Unity: пропы имеют UV 1 ед. = 1 м, значит Tiling = 1 / metres_per_tile (например, Grass → 0.333).

## Импорт в Unity

- Albedo: Texture Type Default, **sRGB (Color Texture) включён**.
- Normal: Texture Type **Normal map** (формат OpenGL, как в Unity, переворачивать Y не нужно).
- Wrap Mode **Repeat**, **Generate Mipmaps** включено, фильтр Bilinear/Trilinear.

## Файлы

- `texlib.py` — бесшовные шумы (value/gradient, fBm на периодической решётке), периодический Voronoi, domain warp,
  цветовые рампы, нормали из высот с учётом обёртки, штамповка фигур с обёрткой, превью и проверка шва.
- `gen_textures.py` — генераторы 10 текстур и CLI.
