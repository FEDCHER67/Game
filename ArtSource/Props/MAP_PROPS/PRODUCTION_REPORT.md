# MAP_PROPS — отчёт о производстве (облако, v01)

Статус: **черновик, Федей не просмотрен.** В Unity ничего не импортировано. Субъективная приёмка вида требует просмотра Федей и проверки в игре.

## Что сделано

Процедурные low-poly пропы для карты. Каждое семейство собирается своим Blender-Python скриптом через общую библиотеку `_lib/mapprops.py`, текстуры генерируются на numpy и Pillow.

| `LAMPS` | MAP-LAMPS-001 | советский бетонный фонарь с «коброй» (целый и разбитый), фонарь старого города (одинарный и двойной) | 284–718 |

Подробности, таблицы и команды сборки — в README каждой папки.

## Соглашения (как у VAN-TIER0 и WATER-TOWER)

- Blender: Z вверх, метры, перед −Y. FBX: axis_forward −Z, axis_up Y, apply_unit_scale, плоское затенение. Один FBX на ассет; корень с пивотом в центре основания на земле.
- Двери и створки ворот — дочерние объекты, пивот на петле. Места источников света — пустышки `*_Light`.
- Общие матовые материалы `MP_*`, без текстур. UV — боксовая проекция, 1 ед. = 1 м, под текстуры из `TEXTURES`.
- `validation_v01.json` в каждой папке: треугольники, габариты, материалы и проверки (замкнутые сетки, нормали наружу, нет вырожденных граней, стоит на земле, пивот в нуле, префиксы имён, бюджет). Во всех семействах `all_checks_passed: true`. Для текстур — `TEXTURES/Out/v01/textures_v01.json`, проверка шва `tileable_ok` у всех.
- Ревизии не перезаписываются без `--force`. Новая версия — новый `--revision`.

## Что в ветке и что нет

Git LFS в облаке заблокирован, поэтому в ветке только скрипты, README и JSON. **.blend, .fbx и .png нужно собрать локально** (из корня репозитория, Python 3.11, `pip install bpy==5.0.1 numpy pillow`):

```
python3 ArtSource/Props/MAP_PROPS/FENCES/build_fences.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/LAMPS/build_lamps.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/GARAGES/build_garages.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/TREES/build_trees.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/BUSHES/build_bushes.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/BEACH/build_beach.py -- --revision 1
python3 ArtSource/Props/MAP_PROPS/TEXTURES/gen_textures.py
```

Вместо `python3` можно запускать через `blender -b --factory-startup --python <скрипт> -- --revision 1`. Сборка в облаке шла через `bpy` 5.0.1 из PyPI, а не Blender 5.2. Рендеры превью — Cycles на CPU, весь набор занимает около 10–15 минут на 4 ядрах; без превью — `--no-render`. Существующая ревизия без `--force` не перезаписывается, поэтому при сборке поверх уже лежащих JSON из ветки добавьте `--force` или соберите `--revision 2`.

## Известные слабые места и что дальше

- Дуб читается скорее как обобщённое лиственное дерево; крона большой берёзы плотновата; бугры изгороди повторяются на длинных рядах, углового модуля нет.
- Асфальт: две заплатки на тайл заметно повторяются. Грязь направленная (колеи вдоль V). У листвы нет альфа-маски.
- Ржавчина и пятна сделаны плоскими цветными латками. Текстуры к пропам не подключены.
- Нет LOD, ветра, коллайдеров и префабов Unity; проверки в Unity не было.
