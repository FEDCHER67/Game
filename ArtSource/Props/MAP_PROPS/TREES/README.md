# MAP-TREES-001 — стилизованные low-poly деревья для карты

Процедурный набор из 6 пород × 2 размера (`_A` крупное, `_B` меньшее — не масштабная копия, а свой seed и пропорции). Стиль — как у NPC «Sausage Buddy» и фасеточного фургона: рубленые формы, плоские матовые цвета (общая палитра `MP_*` из `_lib/mapprops.py`), flat shading, читаемый силуэт, слегка преувеличенные пропорции. Собирается скриптом `build_trees.py` (библиотека `../_lib/mapprops.py`), все seed фиксированы — пересборка даёт тот же результат.

Каждое дерево — **один объект** (ствол + ветки + крона, несколько материалов), все оболочки замкнутые, пивот — центр основания ствола на земле (min z = 0). Единицы — метры, Z вверх; FBX экспортирован с `axis_forward=-Z, axis_up=Y, apply_unit_scale`.

## Сборка (из корня репозитория)

```
python3 ArtSource/Props/MAP_PROPS/TREES/build_trees.py -- --revision 1
```

Нужен модуль `bpy` 5.0.1 с PyPI под Python 3.11: `pip install bpy==5.0.1`. Альтернатива — Blender 5.x в фоне:

```
blender -b --factory-startup --python ArtSource/Props/MAP_PROPS/TREES/build_trees.py -- --revision 1
```

Флаги: `--force` (перезаписать существующую ревизию; по умолчанию скрипт отказывается), `--no-render` (без превью), `--samples N` (сэмплы Cycles, по умолчанию 32; при итерациях 16), `--out DIR` (сборка в другую папку, например черновик в `/tmp`). Новая ревизия модели — новый номер `--revision`, старые файлы не перезаписывать (правило проекта).

Выходы в этой папке: `TR_<Name>_v01.fbx` на каждый ассет (корень в начале координат), `MAP-TREES-001_v01.blend` для ревью (ассеты расставлены рядами: `_B` впереди, `_A` сзади), `validation_v01.json` (треугольники, габариты, материалы, проверки замкнутости/нормалей/пивота — `all_checks_passed: true`), `Previews/v01/*.png` (`01_lineup_front`, `02_lineup_three_quarter`, `03_birch_pine`, `04_oak_poplar`, `05_apple_palm`, `06_street_view` — вид с уровня глаз, 35 мм). Рендер — Cycles CPU, ~20–60 с на картинку на 4 ядрах.

**.blend / .fbx / .png в git не попадают** (LFS в облаке заблокирован) — собирать локально командой выше; в репозитории только скрипт, README и `validation_v01.json`.

## Заметки для Unity

- Ветер и LOD не делались; треугольников хватает на LOD0, LOD1 можно получить decimate-ом в Unity (крона — замкнутые выпуклые клубы, упрощается без дыр).
- Коллайдер: рекомендуется capsule на стволе (радиус у основания — см. `r_base` в `SPECS` скрипта, у дуба/сосны ~0.4–0.55 м); крону не коллайдить.
- Материалы — общие `MP_*` для всех семейств MAP_PROPS: один Unity-материал на имя, плоский цвет без текстур; UV — box-проекция в метрах, если понадобится тайловая текстура.
- Плоское затенение зашито в экспорт (`mesh_smooth_type=FACE`, все грани flat).
