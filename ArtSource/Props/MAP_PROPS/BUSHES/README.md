# MAP-BUSHES-001 — стилизованные low-poly кусты для карты

Четыре процедурных куста в стиле NPC «Sausage Buddy» и фасеточного фургона (рубленые формы, плоские матовые цвета общей палитры `MP_*`, flat shading). Собирается скриптом `build_bushes.py` (библиотека `../_lib/mapprops.py`), seed фиксированы.

Каждый куст — **один объект** с несколькими материалами, все оболочки замкнутые, пивот — центр основания на земле (min z = 0). Метры, Z вверх; FBX с `axis_forward=-Z, axis_up=Y, apply_unit_scale`.

## Сборка (из корня репозитория)

```
python3 ArtSource/Props/MAP_PROPS/BUSHES/build_bushes.py -- --revision 1
```

Нужен модуль `bpy` 5.0.1 с PyPI под Python 3.11: `pip install bpy==5.0.1`. Альтернатива — Blender 5.x в фоне:

```
blender -b --factory-startup --python ArtSource/Props/MAP_PROPS/BUSHES/build_bushes.py -- --revision 1
```

Флаги: `--force` (перезаписать существующую ревизию), `--no-render`, `--samples N` (по умолчанию 32, при итерациях 16), `--out DIR`. Новая ревизия модели — новый номер `--revision`, старые файлы не перезаписывать.

Выходы в этой папке: `BU_<Name>_v01.fbx` на каждый ассет (корень в начале координат), `MAP-BUSHES-001_v01.blend` для ревью (ассеты в ряд вдоль +X), `validation_v01.json` (`all_checks_passed: true`), `Previews/v01/*.png` (`01_lineup_front`, `02_lineup_three_quarter`, `03_hedge_tiled` — три модуля изгороди встык с шагом 2.0 м для проверки стыковки).

**.blend / .fbx / .png в git не попадают** (LFS в облаке заблокирован) — собирать локально; в репозитории только скрипт, README и `validation_v01.json`.

## Заметки для Unity

- Ветер и LOD не делались; кусты и так ≤ 600 треугольников.
- Коллайдеры: кустам — capsule/sphere по центру (или без коллайдера, если по геймплею сквозь кусты можно продираться), изгороди — box 2.0 × 0.7 × 1.1 по пивоту у основания.
- Изгородь ставить модулями с шагом ровно 2.0 м по локальной X (углы — поворот на 90°, стык будет с небольшим нахлёстом; отдельного углового модуля нет).
- Материалы — общие `MP_*` для всех семейств MAP_PROPS, плоские цвета без текстур; UV — box-проекция в метрах.
