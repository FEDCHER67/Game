## Как возобновить

1. Написать в `Escape_Panic_v02/`:
   - `build_esc_panic_v02.py`: драйвер. Импортирует `../Escape_v01/build_esc_v01.py` как модуль. На время импорта поставить `sys.argv=['x']`, потому что модуль парсит argv при импорте. Затем `BE.DEST = HERE` и `sess = BE.Session()`. Паник-спеки добавить в `sess.specs`. Дальше `BE.author/validate/fbx_check/final` и свой authoring_json с полями v01_counterpart и contact_check. Аргументы как в v01: `--clip X --validate --final --stills DIR`, плюс `--strip DIR`.
   - `esc_panic_clips.py`: спеки клипов.
   - `make_sheet_panic_v02.py` и `make_manifest_panic_v02.py`: системный Python + Pillow 12.3.
2. Запуск по одному клипу:
   `"/c/Program Files/Blender Foundation/Blender 5.2/blender.exe" -b --factory-startup --python build_esc_panic_v02.py -- --clip <Name> --validate --final --stills Previews/stills --strip Previews/strips`
   Сессия поднимается за 0.7 с, клип v01 собирается за 3 с.
3. Шов: старт и конец каждого клипа — те же pose keys v01 (LIE/SIT/EDGE_x/LAND_x/DOWN_x/RUN0). `author()` ставит их канонически. Дополнительно сверить с `esc_pose_keys_v01.json`.

## Технические решения (из анализа)

- **Руки на животе.** Добавить каналы: `E.CH += bw_t, bx_t, bz_t, bo_t, ba_t, lbw`. В `E.MIRROR_NEG` добавить `bx_L/bx_R`. Подменить `ctx.ch0` на версию с дефолтами: bx ±0.065, bz 0.92, bo 0.014, ba 20. В `pose_fn`: solve, затем точка живота со скиннинга фронтальных вершин Body (регионы chest/pelvis, гаусс σ≈1.5 см по bind-(x,z)), нормаль поворачивается костью Spine. Цель IK = lerp(tx, точка + n·bo, bw), ладонь = −n, полюс локтя наружу-назад. Потом повторный solve, 2–3 итерации. Взгляд на живот (`lbw`): цель = lerp(lk, живот, lbw/(lbw+look_w)), вес max.
- **Геометрия (bind, лицо −Y).** Перед живота y≈−0.115 при x=0, −0.10 при x=±0.08, −0.077 при x=±0.12. z 0.80–1.04, бока |x|≈0.164. Плечо (0.2, 0, 1.165), плечо + предплечье 0.23 + 0.21, хват ладони 0.055 от запястья. Разрез INC_ABDOMEN: центр (0, −0.118, 0.95), полуширина 0.134, полудлина 0.163. Сидя/наклонясь лучше bz 0.95–0.98, bx 0.10–0.13 (бок): иначе рука упирается в бёдра.
- **Аддитивные слои в `pose_fn`** (дрожь руки, мотание головой, одышка): функции f(t) с огибающей, равной нулю у t=0 и t=T. Иначе будет скачок на шве. В последних ключах явно ставить `bw_*=0, lbw=0`, потому что `lib.rest()/SIT()/EDGE()` этих каналов не содержат и значения унаследуются.
- **Stumble_Off** по контракту — прерывание (удар/укол) после спрыгивания, конец DOWN для рэгдолла. Паник-трактовка: хватается за живот, чуть не падает, ловит равновесие, колени подкашиваются, валится лицом вниз. Руки держит на животе до последнего, на ударе раскидывает. Хвост (с ~1.04 с) — сэмплы кривых v01 со сдвигом +0.2 с, чтобы конец точно совпал с DOWN.
- **SwingOff:** руки на животе, крутится на попе без опоры, проскальзывает за край, ловит себя ладонями. Ладони фиксированы в точках EDGE-plant, конец EDGE с упором ладоней.
- **Leg-клипы:** вторая рука держит бок живота, подпрыгивания (seat↓ + pz 2–4 см) только вне окна контакта 0.80–1.47. LegsBoth: руки чередуются (живот ↔ пряжка), все контакты v01 сохранены.
- **HopRun_BellyClutch:** контракт конца — Flee_Run_v01 кадр 1, так что в последние ~0.2 с руки уходят с живота. Для бега «держась за живот» в игре понадобился бы отдельный луп Flee_Run_BellyClutch. Решить с ведущим.
- **Проверки:** `BE.validate` (зазоры с подушкой, пол, дрейф ремней, самопересечения). Плюс свои: ошибка точки хвата относительно пряжки в кадрах контакта, отклонение вычисленной позы t=0/T от канонической, скорость кистей/стоп на первом и последнем полукадре.
